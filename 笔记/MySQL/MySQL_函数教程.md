# MySQL 函数教程

> 用途：学习笔记 · 定位：只要"技"（怎么用、怎么避坑），不讲"道"
> 覆盖：27. 基础-函数-字符串函数 ~ 31. 基础-函数-小结（共 5 集）
> 所有示例和输出都是在本机 **MariaDB 13.0.2** 上实测跑出来的

---

## 0. 一句话认识

**函数就是"把值扔进去，吐出新值"的加工机。分四类：处理字符串、算数、处理日期、做条件判断。**

| 类别 | 解决什么问题 | 典型函数 |
| --- | --- | --- |
| 字符串函数 | 拼接、截取、大小写、补位 | `CONCAT` / `SUBSTRING` / `UPPER` / `LPAD` |
| 数值函数 | 取整、取余、绝对值、乘方 | `ROUND` / `CEIL` / `FLOOR` / `MOD` |
| 日期函数 | 取年月日、加天数、格式化 | `NOW` / `DATE_ADD` / `DATEDIFF` |
| 流程函数 | 按条件选不同结果 | `IF` / `IFNULL` / `CASE` |

> 这些函数**不改变表里的数据**，只是查询时"算一下"再返回结果。想让改动落库，得配合 `UPDATE ... SET 列 = 函数(...)`。

---

## 1. 为什么需要它

真实业务里，数据存进去的时候是"原始态"，展示和统计时需要加工：

1. **手机号脱敏**：库里存 `13812345678`，页面上要显示 `138****5678` → 字符串函数
2. **按月份统计订单**：库里存了完整 `DATETIME`，只要月份 → 日期函数
3. **金额四舍五入到两位**：浮点算完是 `2.987`，要显示 `2.99` → 数值函数
4. **空值兜底**：某个字段是 NULL，页面上不能显示 "null"，要显示 "暂无" → 流程函数

**这些问题都能在程序里处理，但在数据库里做的好处是：不用把整张大表的数据全传到程序里。**

## 2. 核心用法

### 2.1 字符串函数

| 函数 | 作用 | 例子 | 实测结果 |
| --- | --- | --- | --- |
| `CONCAT(a,b,...)` | 拼接 | `CONCAT('Hello ','MySQL')` | `Hello MySQL` |
| `CONCAT_WS(sep,a,b,...)` | 带分隔符拼接 | `CONCAT_WS('-','2026','11','28')` | `2026-11-28` |
| `LENGTH(s)` | 字节长度 | `LENGTH('你好')` | `6` |
| `CHAR_LENGTH(s)` | 字符长度 | `CHAR_LENGTH('你好')` | `2` |
| `SUBSTRING(s,pos,len)` | 截取 | `SUBSTRING('HelloMySQL',1,5)` | `Hello` |
| `LEFT(s,n)` / `RIGHT(s,n)` | 左/右取 n 个 | `LEFT('HelloMySQL',5)` | `Hello` |
| `UPPER(s)` / `LOWER(s)` | 转大/小写 | `UPPER('abc')` | `ABC` |
| `TRIM(s)` | 去首尾空格 | `TRIM('  ab  ')` | `ab` |
| `LPAD(s,n,pad)` / `RPAD` | 左/右填充到 n 位 | `LPAD('01',5,'0')` | `00001` |
| `REPLACE(s,old,new)` | 替换 | `REPLACE('138-1234-5678','-','')` | `13812345678` |

**⭐ 重点一：LENGTH 和 CHAR_LENGTH 不一样**

```sql
SELECT LENGTH('你好abc') AS 字节数, CHAR_LENGTH('你好abc') AS 字符数;
```

| 字节数 | 字符数 |
| --- | --- |
| 9 | 5 |

「你好」两个汉字在 utf8mb4 下各占 3 字节 = 6，`abc` 3 字节，共 9 字节；但一共只有 5 个字符。

**判断"最多能存几个字"要用 CHAR_LENGTH，判断"占多少空间"才用 LENGTH。** 字段定义 `VARCHAR(10)` 里的 10 是**字符数**，不是字节。

**⭐ 重点二：手机号脱敏实战**

```sql
SELECT CONCAT(SUBSTRING('13812345678',1,3),'****') AS 脱敏;
-- 138****
```

想再完整一点，拼上后 4 位：

```sql
SELECT CONCAT(SUBSTRING(phone,1,3),'****',SUBSTRING(phone,8,4));
```

**⭐ 重点三：LPAD 补位**

```sql
SELECT LPAD('01',5,'0');   -- 00001
```

常用于生成固定长度的编号（订单号 `20261128-00001`）。

### 2.2 数值函数

| 函数 | 作用 | 例子 | 实测结果 |
| --- | --- | --- | --- |
| `ROUND(x,n)` | 四舍五入到 n 位 | `ROUND(2.987,2)` | `2.99` |
| `CEIL(x)` | 向上取整 | `CEIL(1.2)` | `2` |
| `FLOOR(x)` | 向下取整 | `FLOOR(1.8)` | `1` |
| `TRUNCATE(x,n)` | **直接截断**到 n 位 | `TRUNCATE(2.987,2)` | `2.98` |
| `MOD(a,b)` | 取余 | `MOD(10,3)` | `1` |
| `ABS(x)` | 绝对值 | `ABS(-5)` | `5` |
| `POW(x,y)` | 乘方 | `POW(2,10)` | `1024` |
| `RAND()` | 随机数 [0,1) | `RAND()` | 每次不同 |

**⭐ ROUND 和 TRUNCATE 的区别**（这俩最容易被拿来对比）：

| 函数 | 2.987 → 两位 |
| --- | --- |
| `ROUND(2.987,2)` | `2.99`（**看第三位，进位**） |
| `TRUNCATE(2.987,2)` | `2.98`（**直接砍掉，不进位**） |

`ROUND` 适合展示金额；`TRUNCATE` 适合"不许超出"的场合（比如算可用余额，宁可少算不能多算）。

### 2.3 日期函数

| 函数 | 作用 | 例子 | 实测结果 |
| --- | --- | --- | --- |
| `NOW()` | 当前日期+时间 | `NOW()` | `2026-11-28 22:04:55` |
| `CURDATE()` | 当前日期 | `CURDATE()` | `2026-11-28` |
| `CURTIME()` | 当前时间 | `CURTIME()` | `22:04:55` |
| `YEAR(d)` / `MONTH(d)` / `DAY(d)` | 取年/月/日 | `YEAR(NOW())` | `2026` |
| `DATE_ADD(d, INTERVAL n 单位)` | 加时间 | `DATE_ADD('2026-11-28', INTERVAL 7 DAY)` | `2026-12-05` |
| `DATEDIFF(d1,d2)` | 相差天数 | `DATEDIFF('2026-12-01','2026-11-28')` | `3` |
| `DATE_FORMAT(d, fmt)` | 格式化 | `DATE_FORMAT(...,'%Y年%m月%d日')` | `2026年11月28日` |
| `STR_TO_DATE(s, fmt)` | 字符串转日期 | `STR_TO_DATE('2026/11/28','%Y/%m/%d')` | `2026-11-28` |

**⭐ DATE_ADD 的单位**：

```sql
DATE_ADD(日期, INTERVAL 7 DAY)      -- 加 7 天
DATE_ADD(日期, INTERVAL 1 MONTH)    -- 加 1 月
DATE_ADD(日期, INTERVAL -3 DAY)     -- 负数就是减
```

单位可选：`YEAR` / `MONTH` / `DAY` / `HOUR` / `MINUTE` / `SECOND`。

**⭐ DATEDIFF 的顺序**：`DATEDIFF(晚的, 早的)` 返回正数。写反了就是负数，**跟前一个参数减后一个参数**。

**⭐ DATE_FORMAT 常用占位符**：

| 占位符 | 含义 | 例子 |
| --- | --- | --- |
| `%Y` | 四位年 | 2026 |
| `%y` | 两位年 | 26 |
| `%m` | 两位月 | 11 |
| `%d` | 两位日 | 28 |
| `%H` | 24 小时制 | 22 |
| `%i` | 分钟 | 04 |
| `%s` | 秒 | 55 |

> 注意 `%i` 是分钟（不是 `%m`，那是月份），**这是最常见的格式化写错点**。

### 2.4 流程函数

| 函数 | 作用 | 例子 | 实测结果 |
| --- | --- | --- | --- |
| `IF(条件,真值,假值)` | 二选一 | `IF(1>0,'真','假')` | `真` |
| `IFNULL(值,兜底)` | 值是 NULL 就用兜底 | `IFNULL(NULL,'默认值')` | `默认值` |
| `COALESCE(a,b,c...)` | 取第一个非 NULL | `COALESCE(NULL,NULL,'兜底值')` | `兜底值` |
| `CASE WHEN ... THEN ... END` | 多分支（条件式） | `CASE WHEN 2>1 THEN '大于' ELSE '不大于' END` | `大于` |
| `CASE x WHEN ... THEN ... END` | 多分支（等值式） | `CASE 3 WHEN 1 THEN '一' WHEN 2 THEN '二' ELSE '其他' END` | `其他` |

**⭐ IFNULL 是最常用的一个**：表里某列是 NULL，查询时直接兜底，程序里就不用判空。

```sql
SELECT name, IFNULL(workaddress, '未填写') AS 地址 FROM emp;
```

**⭐ CASE 的两种写法**：

```sql
-- 条件式：每个 WHEN 后面跟一个完整条件
CASE WHEN age < 18 THEN '未成年'
     WHEN age < 60 THEN '成年'
     ELSE '老年' END

-- 等值式：CASE 后面跟一个值，WHEN 后面跟要匹配的值
CASE gender WHEN '男' THEN '先生'
            WHEN '女' THEN '女士'
            ELSE '未知' END
```

两者**不能混用**：等值式的 `CASE x WHEN` 后面只能放值，不能放 `x > 5` 这种表达式。

## 3. 常见坑汇总

| # | 坑 | 现象 | 正确做法 |
| --- | --- | --- | --- |
| 1 | 用 `LENGTH` 判断能存几个字 | 把汉字算成 3 个 | 用 `CHAR_LENGTH` |
| 2 | `ROUND` 和 `TRUNCATE` 混用 | 金额被截断而不是四舍五入 | 展示用 ROUND，宁少勿多用 TRUNCATE |
| 3 | `DATE_FORMAT` 把 `%i` 写成 `%m` | 分钟变成月份 | `%i` 是分钟 |
| 4 | `DATEDIFF` 参数顺序写反 | 得到负数 | 晚的在前 |
| 5 | `CASE WHEN` 和 `CASE 值` 混写 | 语法错 | 分开用，别杂交 |
| 6 | 在 WHERE 里用函数做列运算 | 索引失效，全表扫描 | `WHERE 函数(列)` 尽量改成 `WHERE 列 = 值` |
| 7 | `CONCAT` 里混进 NULL | 整个结果变 NULL | 用 `CONCAT_WS` 或先 `IFNULL` |

> 坑 6 展开：`WHERE DATE(created_at) = '2026-11-28'` 这种写法会让索引失效（因为对列做了运算）。正确做法是 `WHERE created_at >= '2026-11-28' AND created_at < '2026-11-29'`。等学到索引那章会再讲。

## 4. 什么时候用 / 不用

| 该用 | 不该用 |
| --- | --- |
| 展示前加工（脱敏、格式化、兜底） | 把复杂业务计算塞进 SQL（可读性差、难测） |
| 简单统计（按月分组、算年龄） | 在 WHERE 里对列套函数（吃索引） |
| `IFNULL` 兜底避免程序判空 | 用函数改数据又不写 UPDATE（只算不存） |
