# Java 包装类教程

> 用途：学习笔记 · 定位：只要"技"（怎么用、怎么避坑），不讲"道"（源码、IntegerCache 实现）
> 所有示例和输出都是在本机 JDK 27 上用 jshell 实测跑出来的

---

## 0. 一句话认识

**包装类 = 把 8 种基本类型包成对象。**

为什么要包成对象？三个现实原因：

| 原因 | 例子 |
|---|---|
| **泛型只能放对象** | `List<Integer>` 合法，`List<int>` 编译错误 |
| **需要 null 表示"没有值"** | 数据库字段、JSON、`Map.get()` 找不到 |
| **需要类的方法** | `Integer.parseInt()`、`Character.isDigit()` |

**一句话选择**：能确定有值且不需要放进集合 → 用基本类型；需要 null、泛型、集合、反射 → 用包装类。

## 1. 八个包装类一览

| 基本类型 | 包装类 | 常用 |
|---|---|---|
| `byte` | `Byte` | 少用 |
| `short` | `Short` | 少用 |
| **`int`** | **`Integer`** | ★★★ 最常用 |
| **`long`** | **`Long`** | ★★★ 最常用 |
| `float` | `Float` | 少用 |
| **`double`** | **`Double`** | ★★ 常用 |
| **`char`** | **`Character`** | ★★ 常用 |
| **`boolean`** | **`Boolean`** | ★★ 常用 |

**记法**：除了 `int → Integer`、`char → Character`，其余都是**首字母大写**。

**注意大小写！** `Integer` 不是 `Interger`，`Character` 不是 `Charactor` —— 这两个拼错最常见。

## 2. 装箱和拆箱

### 2.1 手动装箱、拆箱

```java
// 装箱：基本类型 -> 包装类
Integer a = Integer.valueOf(100);   // 推荐
Integer b = new Integer(100);       // 已废弃，别用（JDK 9 起废弃）

// 拆箱：包装类 -> 基本类型
int x = a.intValue();
```

### 2.2 自动装箱、拆箱（JDK 5+，现在几乎不用手动）

```java
Integer i = 10;        // 自动装箱：等价于 Integer.valueOf(10)
int j = i;             // 自动拆箱：等价于 i.intValue()

Integer sum = i + 5;   // 先拆箱运算，再把结果装箱
// sum = 15
```

**编译器帮你做的**：看到 `Integer i = 10` 就自动补 `Integer.valueOf(10)`，看到 `int j = i` 就补 `i.intValue()`。

### 2.3 坑：自动拆箱会 NPE（最重要）

**只要包装类是 null，任何"当基本类型用"的地方都会炸：**

```java
Integer n = null;

// 场景 1：赋值给 int
int x = n;                  // ❌ NPE

// 场景 2：参与运算
System.out.println(n + 1);  // ❌ NPE

// 场景 3：和基本类型比较（== 也会拆箱）
System.out.println(n == 1); // ❌ NPE
```

实测报错：

```
Cannot invoke "java.lang.Integer.intValue()" because "n" is null
```

**场景 3 最坑**：`n == 1` 看起来是"比较"，其实 `1` 是 int，所以 `n` 会被拆箱 → NPE。

**安全写法**：用 `Objects.equals(n, 1)`，null 时返回 false 不炸。

```java
Objects.equals(null, 1);   // false，不抛异常
```

### 2.4 坑：三元运算符里的隐形拆箱

```java
Integer i = null;
Integer r = true ? i : 0;   // ❌ NPE！
```

**原因**：三元表达式两侧一边是 `Integer`、一边是 `int`，Java 会把整个结果**提升成 int**，于是 `i` 被拆箱 → NPE。

**怎么避免**：两边类型保持一致，都写 `Integer`：

```java
Integer r = true ? i : Integer.valueOf(0);   // 安全
```

## 3. Integer 缓存（最坑的知识点）

### 3.1 现象：127 相等，128 不相等

```java
Integer a = 127, b = 127;
a == b;      // true

Integer c = 128, d = 128;
c == d;      // false   ← 同样的值，结果不一样！
```

实测：

```
127 == 127  : true
128 == 128  : false
-128 == -128: true
-129 == -129: false
```

### 3.2 原因（一句话就够）

**`Integer.valueOf()` 在 -128 ~ 127 范围里返回的是缓存好的同一个对象**，超出范围才 new 新对象。

`Integer a = 127` 编译后就是 `Integer.valueOf(127)`，所以两个 127 拿到同一个缓存对象 → `==` 为 true。128 超出缓存 → 各 new 一个 → `==` 为 false。

**范围：-128 ~ 127**（可以用 JVM 参数 `-XX:AutoBoxCacheMax` 调大上限，但默认就是这个）。

### 3.3 各包装类的缓存范围

| 类型 | 缓存范围 | 说明 |
|---|---|---|
| `Byte` | 全部（-128~127） | 全缓存 |
| `Short` | -128 ~ 127 | |
| **`Integer`** | **-128 ~ 127** | 最常考 |
| `Long` | -128 ~ 127 | |
| `Character` | 0 ~ 127（ASCII） | |
| `Boolean` | `true` / `false` 两个 | |
| `Float` | **无缓存** | |
| `Double` | **无缓存** | |

实测：

```
Long 127/128    : true / false
Short 127/128   : true / false
Character 'a'/'a': true
Boolean true/true: true
Double 1.0/1.0  : false   ← Double 没有缓存，永远不相等
```

### 3.4 `valueOf` 和 `new` 的区别

```java
Integer.valueOf(127) == Integer.valueOf(127);   // true（走缓存）
Integer.valueOf(128) == Integer.valueOf(128);   // false（超出缓存）

new Integer(127) == new Integer(127);           // false（new 一定造新对象）
```

**记住：`new` 一定造新对象，缓存失效。**

### 3.5 正经结论

> **比较包装类的值，永远用 `equals()` 或 `compareTo()`，永远不要用 `==`。**

```java
Integer a = 128, b = 128;
a == b;              // false ❌ 别用
a.equals(b);         // true  ✅ 正确
a.compareTo(b) == 0; // true  ✅ 也可以
```

## 4. `==` 和 `equals` 铁律

| 写法 | 比较什么 | 可靠性 |
|---|---|---|
| `a == b`（都是包装类） | 是不是**同一个对象** | ❌ 受缓存影响，结果随机 |
| `a.equals(b)` | **值**是否相等 | ✅ 可靠 |
| `a.compareTo(b) == 0` | 值大小 | ✅ 可靠 |
| `a == b`（一个包装一个基本） | **自动拆箱**后比值 | ⚠️ 值对，但 null 会 NPE |

**一句话：包装类比较只用 `equals` / `compareTo`。**

## 5. 常用方法速查

### 5.1 Integer / Long / Double 通用方法

```java
// 字符串 -> 基本类型
Integer.parseInt("123");       // 123（int）
Long.parseLong("123");         // 123L
Double.parseDouble("1.5");     // 1.5

// 字符串 -> 包装类（可能走缓存）
Integer.valueOf("123");        // Integer 对象
Integer.valueOf(123);          // Integer 对象

// 包装类 -> 基本类型
Integer i = 123;
i.intValue();                  // 123
i.longValue();                 // 123L
i.doubleValue();               // 123.0

// 基本类型 -> 字符串
String.valueOf(123);           // "123"
Integer.toString(123);         // "123"
123 + "";                      // "123"（偷懒写法）
```

### 5.2 坑：字符串转数字会抛异常

```java
Integer.parseInt("12a");
// 抛 NumberFormatException: For input string: "12a"
```

**必须 try-catch，或者先判断格式：**

```java
try {
    int n = Integer.parseInt(str);
} catch (NumberFormatException e) {
    // 处理非法输入
}
```

### 5.3 进制转换（Integer 独有）

```java
Integer.toBinaryString(255);   // "11111111"
Integer.toOctalString(255);    // "377"
Integer.toHexString(255);      // "ff"
Integer.toString(255, 36);     // "73"（按 36 进制）

Integer.parseInt("ff", 16);    // 255（把 16 进制字符串转成 int）
```

### 5.4 Character 常用方法

```java
Character.isDigit('5');          // true    是不是数字字符
Character.isLetter('a');         // true    是不是字母
Character.isLetterOrDigit('_');  // false   下划线不算！实测确认
Character.isWhitespace(' ');     // true    是不是空白
Character.isUpperCase('A');      // true    是不是大写
Character.isLowerCase('a');      // true    是不是小写
Character.toUpperCase('a');      // 'A'     转大写
Character.toLowerCase('A');      // 'a'     转小写
Character.getNumericValue('7');  // 7       字符数字转 int
```

### 5.5 坑：`Boolean.parseBoolean` 不报错但很危险

```java
Boolean.parseBoolean("true");    // true
Boolean.parseBoolean("TRUE");    // true   ← 忽略大小写
Boolean.parseBoolean("abc");     // false  ← 不抛异常！
Boolean.parseBoolean("1");       // false  ← 1 也不算 true
```

**只有忽略大小写的 `"true"` 才是 true，其他一律 false，而且不报错。** 用户输入非法内容时你会静默拿到 false，很难查。

### 5.6 比较和取大小

```java
Integer.compare(1, 2);          // -1
Integer.compare(2, 2);          // 0
Integer.compare(3, 2);          // 1

Integer.max(3, 7);              // 7
Integer.min(3, 7);              // 3

Integer a = 5;
a.compareTo(3);                 // 1
```

### 5.7 常量（判断边界用）

```java
Integer.MAX_VALUE;   // 2147483647
Integer.MIN_VALUE;   // -2147483648
Long.MAX_VALUE;      // 9223372036854775807
```

**注意：包装类救不了溢出。**

```java
Integer.MAX_VALUE + 1;   // -2147483648  ← 溢出变负，不报错
```

真正要算大数用 `BigInteger`（之前学过）。

## 6. 和 String 互转（高频）

### 6.1 数字 → 字符串（三种写法都行）

```java
int n = 123;
String s1 = String.valueOf(n);     // "123"  ✅ 推荐
String s2 = Integer.toString(n);   // "123"
String s3 = n + "";                // "123"  偷懒写法，可读性差
```

### 6.2 字符串 → 数字（两种，注意区别）

```java
String s = "123";

int a = Integer.parseInt(s);       // 返回 int（基本类型）
Integer b = Integer.valueOf(s);    // 返回 Integer（对象）

// 区别就在返回值类型，需要对象（放集合里）用 valueOf
```

### 6.3 字符串 → 其他类型

```java
Long.parseLong("123");             // 123L
Double.parseDouble("1.5");         // 1.5
Boolean.parseBoolean("true");      // true（坑见 5.5）
Float.parseFloat("1.5f");          // 1.5f
```

## 7. 实战场景

### 7.1 集合里只能用包装类

```java
List<Integer> list = new ArrayList<>();
list.add(1);          // 自动装箱
list.add(2);

int x = list.get(0);  // 自动拆箱
```

`List<int>` 编译不过，因为泛型只接受对象。

### 7.2 坑：`List.remove` 的歧义（经典面试题）

```java
List<Integer> list = new ArrayList<>();
list.add(10); list.add(20); list.add(30);

list.remove(1);        // 删的是【索引 1】的元素（20），不是值 1
// 结果：[10, 30]

list.remove(Integer.valueOf(1));   // 删的是【值 1】的元素
```

**原因**：`List` 有 `remove(int index)` 和 `remove(Object o)` 两个重载，传 `int` 走索引版本，传 `Integer` 走对象版本。

**记忆**：`remove(int)` 删索引；`remove(Object)` 删值。想删值必须包成 `Integer`。

### 7.3 Map 里"找不到"返回 null

```java
Map<Integer, String> map = new HashMap<>();
map.put(1, "one");

map.get(1);     // "one"
map.get(2);     // null     ← 不存在就是 null
map.getOrDefault(2, "默认");   // "默认"  ✅ 推荐用法
```

**注意**：`map.get(key)` 返回 null 有两种可能——key 不存在，或者 key 存在但值就是 null，区分不了。要判断用 `containsKey()`。

### 7.4 数据库 / JSON 里的 null

```java
// 数据库字段可以为空时，实体类用包装类
class User {
    Integer age;     // 没填就是 null
    int age2;        // 没填是 0 —— 但 0 岁和"没填"分不清
}
```

**结论**：需要区分"没有值"和"值是 0"时，必须用包装类。

### 7.5 默认值对照（重要）

```java
class Box {
    Integer num;    // 默认 null
    int prim;       // 默认 0
}

new Box().num;      // null
new Box().prim;     // 0

Integer[] arr1 = new Integer[3];   // [null, null, null]
int[] arr2 = new int[3];           // [0, 0, 0]
```

**包装类字段默认 null，直接拿去运算就 NPE**（见 2.3）。

## 8. 常见错误速查（照着躲）

| ❌ 错法 | ✅ 对法 | 后果 |
|---|---|---|
| `a == b` 比较两个 Integer | `a.equals(b)` | 127 相等、128 不等，随机 bug |
| `new Integer(100)` | `Integer.valueOf(100)` | 已废弃（JDK 9 起），而且不走缓存 |
| `Integer i = null; int x = i;` | 先判空 | NPE |
| `Integer i = null; i == 1` | `Objects.equals(i, 1)` | NPE（`==` 会拆箱） |
| `true ? nullInteger : 0` | 两边都用 Integer | 三元运算符隐形拆箱 NPE |
| `list.remove(1)` 想删值 1 | `list.remove(Integer.valueOf(1))` | 删掉索引 1 的元素 |
| `Integer.parseInt("abc")` 不捕获 | try-catch `NumberFormatException` | 直接崩 |
| `Boolean.parseBoolean("1")` | 自己判断 | 静默返回 false |
| `Integer.MAX_VALUE + 1` | 用 `BigInteger` | 溢出变负数，不报错 |
| 用包装类做循环计数器 | 用 `int` | 每次循环都装箱，慢 |

## 9. 一页速查表

### 转换

| 方向 | 写法 |
|---|---|
| `int` → `Integer` | `Integer.valueOf(n)` 或直接赋值（自动装箱） |
| `Integer` → `int` | `i.intValue()` 或直接赋值（自动拆箱） |
| `String` → `int` | `Integer.parseInt("123")` |
| `String` → `Integer` | `Integer.valueOf("123")` |
| `int` → `String` | `String.valueOf(n)` |
| `int` → 其他进制字符串 | `Integer.toBinaryString/toHexString/toOctalString` |
| `char` → `Character` | 自动装箱 |
| `Character` 判断 | `isDigit/isLetter/isWhitespace` |

### 比较

| 想要 | 写法 |
|---|---|
| 值相等 | `a.equals(b)` |
| 大小 | `a.compareTo(b)` 或 `Integer.compare(a, b)` |
| 取大/小 | `Integer.max/min` |
| 安全判空比较 | `Objects.equals(a, b)` |

### 记住的常量

| 常量 | 值 |
|---|---|
| `Integer.MAX_VALUE` | 2147483647 |
| `Integer.MIN_VALUE` | -2147483648 |
| 缓存范围 | -128 ~ 127 |
| `Double`/`Float` 缓存 | **无** |

## 10. 动手练习（直接 jshell 敲）

```bash
jshell
```

```java
import java.util.*;

// ① 验证缓存：127 和 128
Integer a = 127, b = 127;
Integer c = 128, d = 128;
System.out.println("127 == 127: " + (a == b));
System.out.println("128 == 128: " + (c == d));
System.out.println("128 equals: " + c.equals(d));

// ② 踩拆箱 NPE
Integer n = null;
try { int x = n; } catch (NullPointerException e) { System.out.println("NPE 了"); }

// ③ 三元运算符的坑
try { Integer r = true ? null : 0; } catch (NullPointerException e) { System.out.println("三元也 NPE"); }

// ④ List.remove 的歧义
List<Integer> list = new ArrayList<>(List.of(10, 20, 30));
list.remove(1);
System.out.println(list);
List<Integer> list2 = new ArrayList<>(List.of(1, 2, 3));
list2.remove(Integer.valueOf(1));
System.out.println(list2);

// ⑤ 进制转换
System.out.println(Integer.toBinaryString(255));
System.out.println(Integer.toHexString(255));

// ⑥ 字符串转数字必须处理异常
try {
    System.out.println(Integer.parseInt("12a"));
} catch (NumberFormatException e) {
    System.out.println("非法输入: " + e.getMessage());
}
```

## 记忆口诀

> **包装类就是基本类型的对象壳，泛型集合离不开它；**
> **127 相等 128 不等，因为有个缓存圈；**
> **比较数值用 equals，== 是比对象别用；**
> **null 拆箱必 NPE，三元混用也中招；**
> **remove 传 int 删索引，要删值就包成 Integer。**
