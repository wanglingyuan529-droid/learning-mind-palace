## 0. 方法引用是什么（01）

### 0.1 一句话

**方法引用 = lambda 的"再简化"**。

**当 lambda 体只是在"调用一个现成的方法"时，可以直接写方法名，不用写参数。**

### 0.2 先看对比

```java
// lambda 写法
Function<String, Integer> f1 = s -> Integer.parseInt(s);

// 方法引用写法
Function<String, Integer> f2 = Integer::parseInt;
```

**两行完全等价**，方法引用更短、更直观。

### 0.3 什么情况下能用

**只有一个条件：lambda 体里只有"一个方法调用"，没有别的逻辑。**

```java
// ✅ 可以用方法引用：只调用 parseInt
s -> Integer.parseInt(s)          →  Integer::parseInt

// ❌ 不能用：有额外逻辑（乘 2）
s -> Integer.parseInt(s) * 2      →  只能写 lambda

// ❌ 不能用：有多个语句
s -> { System.out.println(s); return s.length(); }   →  只能写 lambda
```

**判断口诀**：**"参数原样传给方法" → 能简化成方法引用。**

### 0.4 为什么叫"方法引用"

因为它**引用**了一个已经存在的方法（`Integer.parseInt`），而不是重新写一遍逻辑。

**格式**：`目标::方法名`，中间是**两个冒号**。

## 1. 五种形式（02–06）

> **这是本节最核心的内容。五种形式的名字很像，但写法不同。**

### 形式 1：引用静态方法（02）

**格式**：`类名::静态方法名`

```java
// lambda
Function<String, Integer> f1 = s -> Integer.parseInt(s);

// 方法引用
Function<String, Integer> f2 = Integer::parseInt;

f2.apply("123");    // 123
```

**Stream 里最常用：**

```java
List<String> strs = List.of("1", "2", "3");

// 字符串列表转 int 列表
strs.stream().map(Integer::parseInt).toList();       // [1, 2, 3]

// 转 int 再求和
strs.stream().mapToInt(Integer::parseInt).sum();     // 6
```

**记忆**：静态方法是"类的方法"，所以用 `类名::方法名`。

---

### 形式 2：引用其它类的成员方法（03）

**格式**：`对象名::方法名`（注意：是**对象**，不是类）

```java
List<String> names = List.of("tom", "jerry");

// lambda
names.forEach(s -> System.out.println(s));

// 方法引用（System.out 是一个对象）
names.forEach(System.out::println);
```

**对比：**

| 写法 | 含义 |
|---|---|
| `Integer::parseInt` | **类名**::静态方法 |
| `System.out::println` | **对象**::实例方法（`System.out` 是 PrintStream 对象） |

**其它例子：**

```java
Consumer<String> c = System.out::println;    // 打印
c.accept("hello");                            // hello
```

---

### 形式 3：引用本类或父类的成员方法（04）

**格式**：`this::方法名` 或 `super::方法名`

```java
class A {
    void print(String s) {
        System.out.println("A 打印: " + s);
    }
}

class B extends A {
    void test() {
        // 引用本类的方法
        Consumer<String> c1 = this::print;
        c1.accept("来自 B");

        // 引用父类的方法
        Consumer<String> c2 = super::print;
        c2.accept("来自父类");
    }
}
```

**实测输出：**

```
A 打印: 来自 B
A 打印: 来自父类
```

**这个形式在写回调、排序比较器时偶尔用到**，但不是高频。

---

### 形式 4：引用构造方法（05）

**格式**：`类名::new`

```java
// lambda
Function<String, StringBuilder> f1 = s -> new StringBuilder(s);

// 方法引用
Function<String, StringBuilder> f2 = StringBuilder::new;

f2.apply("abc");    // "abc"
```

**Stream 里最常用：把数据转成对象**

```java
// 假设 Person 有个构造器 Person(String s)，能把 "张三,25" 解析成对象
List<String> data = List.of("张三,25", "李四,20", "王五,30");

List<Person> people = data.stream()
        .map(Person::new)       // 每条数据 → 一个 Person 对象
        .toList();
// [张三:25, 李四:20, 王五:30]
```

**`Person::new` 会自动匹配"参数个数和类型对得上"的构造器。**

---

### 形式 5：类名引用成员方法（06，最容易懵）

**格式**：`类名::实例方法名`

**这个形式特殊在哪**：它引用的虽然是"实例方法"，但前面写的是**类名**，不是对象名。

**规则**：**第一个参数作为"调用者"，其余参数作为方法的参数。**

```java
// 平时写：
s -> s.toUpperCase()

// 方法引用：
String::toUpperCase

// 规则：第一个参数 s 作为调用者 → s.toUpperCase()
```

**看几个例子：**

```java
// ① 一个参数
Function<String, String> upper = String::toUpperCase;
upper.apply("hello");      // "HELLO"
// 等价于 s -> s.toUpperCase()

// ② 两个参数：第一个是调用者，第二个是参数
BiFunction<String, String, Boolean> starts = String::startsWith;
starts.apply("hello", "he");    // true
// 等价于 (a, b) -> a.startsWith(b)

// ③ 排序时用
List.of("B", "a", "C").stream()
    .sorted(String::compareToIgnoreCase)
    .toList();
// [a, B, C]
// 等价于 (a, b) -> a.compareToIgnoreCase(b)
```

**为什么需要这个形式？**

因为 `map`、`sorted` 这些方法接收的函数式接口，参数是"数据本身"，而你恰好要调用**数据对象自己的方法**。

```java
list.stream().map(String::toUpperCase)
// 等价于
list.stream().map(s -> s.toUpperCase())
```

## 2. 引用数组的构造方法（07）

**格式**：`数组类型::new`

```java
// lambda
Function<Integer, int[]> f1 = n -> new int[n];

// 方法引用
Function<Integer, int[]> f2 = int[]::new;

f2.apply(3);    // [0, 0, 0]
```

**Stream 里最常用：把流收集成数组**

```java
List<String> list = List.of("a", "b", "c");

// 收集成 String[]
String[] array = list.stream().toArray(String[]::new);
// [a, b, c]
```

**注意**：`toArray()` 不传参数返回 `Object[]`，传 `String[]::new` 才是 `String[]`。

## 3. 五种形式总对比

| 形式 | 写法 | 例子 | 记忆 |
|---|---|---|---|
| 静态方法 | `类名::静态方法` | `Integer::parseInt` | 类的方法，类名开头 |
| 其它类成员方法 | `对象::方法` | `System.out::println` | **对象**的方法，对象名开头 |
| 本类/父类方法 | `this::方法` / `super::方法` | `this::print` | 特殊关键字 |
| 构造方法 | `类名::new` | `StringBuilder::new` | 类名 + new |
| 类名引用成员方法 | `类名::实例方法` | `String::toUpperCase` | 第一个参数当调用者 |
| 数组构造 | `数组类型::new` | `int[]::new` | 类型 + new |

**最容易混的是第 2 和第 5**：

```java
System.out::println      // 对象::方法 —— System.out 是对象
String::toUpperCase      // 类名::方法 —— String 是类，第一个参数当调用者
```

**判断方法**：
- 冒号前面是**对象**（变量）→ 形式 2
- 冒号前面是**类名**，且方法不是 static → 形式 5

## 4. 练习（08）

### 练习 1：转成自定义对象并收集

**需求**：有一堆字符串 `"张三,25"`，转成 `Person` 对象列表。

```java
class Person {
    String name;
    int age;

    // 构造器：解析 "张三,25"
    Person(String s) {
        String[] parts = s.split(",");
        this.name = parts[0];
        this.age = Integer.parseInt(parts[1]);
    }

    // getter（方法引用要用到）
    String getName() { return name; }
    int getAge() { return age; }

    @Override public String toString() { return name + ":" + age; }
}

List<String> data = List.of("张三,25", "李四,20", "王五,30");

List<Person> people = data.stream()
        .map(Person::new)      // 构造方法引用
        .toList();

// [张三:25, 李四:20, 王五:30]
```

**注意**：`Person::new` 能用的前提是**存在一个 `Person(String)` 的构造器**。

### 练习 2：获取部分属性并收集到数组

**需求**：从 `Person` 列表里只取名字、只取年龄。

```java
// 只要名字 → String[]
String[] names = people.stream()
        .map(Person::getName)      // 类名::实例方法
        .toArray(String[]::new);
// [张三, 李四, 王五]

// 只要年龄 → int[]
int[] ages = people.stream()
        .mapToInt(Person::getAge)  // mapToInt 返回 IntStream
        .toArray();
// [25, 20, 30]
```

**提醒**：`Person::getName` 能用的前提是** Person 类真的定义了 `getName()` 方法**。（我实测时就因为没写 getter 报错了：`cannot find symbol: method getName()`）

## 5. 常见用法速查（实战）

```java
// 遍历打印
list.forEach(System.out::println);

// 转 int
list.stream().map(Integer::parseInt).toList();

// 转大写
list.stream().map(String::toUpperCase).toList();

// 取长度
list.stream().map(String::length).toList();

// 过滤 null
list.stream().filter(Objects::nonNull).toList();

// 排序（忽略大小写）
list.stream().sorted(String::compareToIgnoreCase).toList();

// 转对象
data.stream().map(Person::new).toList();

// 转数组
list.stream().toArray(String[]::new);

// 收集成 Map
list.stream().collect(Collectors.toMap(Person::getName, Person::getAge));
```

## 6. 一页速查表

| 需求 | 写法 |
|---|---|
| 静态方法 | `类名::静态方法` |
| 对象的实例方法 | `对象::方法` |
| 本类方法 | `this::方法` |
| 父类方法 | `super::方法` |
| 构造方法 | `类名::new` |
| 类名引用实例方法 | `类名::方法`（第一个参数当调用者） |
| 数组构造 | `数组类型::new` |

---

## 7. 常见错误

| ❌ 错法 | ✅ 对法 | 原因 |
|---|---|---|
| `s -> Integer.parseInt(s) * 2` 写成 `Integer::parseInt * 2` | 保持 lambda | 方法引用不能带额外运算 |
| `String::toUpperCase` 当"对象的方法"理解 | 它是"类名::实例方法"：第一个参数当调用者 | 概念混淆 |
| `Person::getName` 报 cannot find symbol | 类里要真的有 getName() | 方法不存在 |
| `person::getName` 写成 `Person::getName` 但 person 是变量 | 看冒号前是对象还是类 | 形式 2 vs 形式 5 |
| `toArray()` 返回 `Object[]` 却当 `String[]` 用 | `toArray(String[]::new)` | 类型不对 |
| 在 jshell 里链式调用跨行 | 写一行 | jshell 逐行解析 |

```java
import java.util.*;
import java.util.stream.*;

// ① 静态方法引用
List<String> nums = List.of("1", "2", "3");
System.out.println(nums.stream().map(Integer::parseInt).toList());

// ② 对象方法引用

System.out.println(List.of("a", "b").stream().map(StringBuilder::new).toList());

String[] arr = List.of("a", "b").stream().toArray(String[]::new);
System.out.println(Arrays.toString(arr));
```

## 记忆口诀

> **方法引用是 lambda 的简写，参数原样传才能用；**
> **静态方法类名引，对象方法对象引，this/super 管本家；**
> **构造方法类名 new，数组类型加 new；**
> **类名引实例方法，第一个参数当调用者。**

## 附：和 lambda 的换算表

| lambda | 方法引用 |
|---|---|
| `s -> Integer.parseInt(s)` | `Integer::parseInt` |
| `s -> System.out.println(s)` | `System.out::println` |
| `s -> s.toUpperCase()` | `String::toUpperCase` |
| `(a, b) -> a.startsWith(b)` | `String::startsWith` |
| `s -> new Person(s)` | `Person::new` |
| `n -> new int[n]` | `int[]::new` |
| `s -> s.length()` | `String::length` |
| `s -> Objects.nonNull(s)` | `Objects::nonNull` |

**看到方法引用，可以在脑子里"翻译"成 lambda 来理解。**
