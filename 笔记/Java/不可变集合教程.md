## 0. 什么是不可变集合

**不可变集合 = 创建以后就改不了的集合。**

```java
List<String> list = List.of("a", "b", "c");

list.add("d");      // ❌ UnsupportedOperationException
list.set(0, "z");   // ❌ UnsupportedOperationException
list.remove(0);     // ❌ UnsupportedOperationException
list.clear();       // ❌ UnsupportedOperationException

list.get(1);        // ✅ "b"   读没问题
list.size();        // ✅ 3
```

**一句话**：**只能读，不能写**。

---

## 1. 为什么需要不可变集合

### 理由 1：防止数据被意外改掉

**场景**：你写了一个方法，返回配置信息：

```java
// ❌ 可变集合：调用方拿到以后可以随便改
public List<String> getRoles() {
    return roles;     // 返回内部字段，外面一改就污染了
}

// ✅ 不可变集合：调用方怎么都改不了
public List<String> getRoles() {
    return List.of("admin", "guest");
}
```

**多个方法共用一个配置、一个常量列表时，不可变集合能保证"谁都用不坏"。**

### 理由 2：线程安全

**不可变集合天生线程安全**——因为没人能改它，自然不会有并发修改问题。

```java
// 多个线程同时读同一个不可变集合，完全没问题
static final List<String> ROLES = List.of("admin", "guest", "user");
```

### 理由 3：当作常量来用

```java
// 以前只能用数组当常量，还得担心被改
static final String[] COLORS = {"red", "green"};

// 现在直接用不可变集合
static final List<String> COLORS = List.of("red", "green", "blue");
```

## 2. 怎么创建（JDK 9+ 的工厂方法）

### 2.1 List.of()

```java
List<String> empty = List.of();              // 空列表
List<String> one   = List.of("a");           // 一个元素
List<String> multi = List.of("a", "b", "c"); // 多个元素
List<Integer> nums = List.of(1, 2, 3);       // 自动装箱
```

### 2.2 Set.of()

```java
Set<String> empty = Set.of();
Set<String> set   = Set.of("a", "b", "c");
```

### 2.3 Map.of()

```java
Map<String, Integer> empty = Map.of();
Map<String, Integer> one   = Map.of("a", 1);
Map<String, Integer> multi = Map.of("a", 1, "b", 2);
```

**注意 Map.of 的参数是"键, 值, 键, 值..."交替排列**，不是 `Map.of(key, value)` 的形式。

### 2.4 从已有集合拷贝

```java
List<String> src = new ArrayList<>(List.of("a", "b"));

List<String> copy = List.copyOf(src);   // 拷贝一份不可变的
Set<String>  copy2 = Set.copyOf(src);
Map<String, Integer> copy3 = Map.copyOf(Map.of("a", 1));
```

**`copyOf` 和 `of` 的区别**：`copyOf` 是从已有集合复制，`of` 是直接给元素。

## 3. 三个硬性规则（必记）

### 规则 1：任何"写"操作都抛异常

```java
List.of("a").add("b");      // UnsupportedOperationException
List.of("a").set(0, "b");   // UnsupportedOperationException
List.of("a").remove(0);     // UnsupportedOperationException
List.of("a").clear();       // UnsupportedOperationException
```

**连 `set`（替换元素）都不行**——这是和 `Arrays.asList` 最大的区别。

### 规则 2：不能放 null

```java
List.of("a", null);     // ❌ NullPointerException
Set.of("a", null);      // ❌ NullPointerException
Map.of("a", null);      // ❌ NullPointerException（值是 null 也不行）
```

**为什么？** 因为不可变集合内部用"null 表示空位"，如果真放 null 进去就分不清了。所以 JDK 直接禁止。

### 规则 3：Set 和 Map 不能有重复

```java
Set.of("a", "b", "a");
// ❌ IllegalArgumentException: duplicate element: a

Map.of("a", 1, "a", 2);
// ❌ IllegalArgumentException: duplicate key: a
```

**注意**：普通 `Set` 遇到重复元素是"静默去重"（加不进去），**但 `Set.of` 是直接抛异常**。

**为什么？** 因为 `Set.of` 认为"你传重复元素肯定是写错了"，宁可报错也不悄悄帮你改。

## 4. Map.of 的 10 对限制（反直觉的坑）

**`Map.of` 最多只能传 10 对键值对。** 超过 10 对会怎样？

**实测结果：不是运行时异常，是编译错误！**

```java
// 11 对 → 编译错误
Map.of("k1",1, "k2",2, ..., "k11",11);
// error: no suitable method found for of(...)
```

**为什么？** 因为 JDK 给 `Map.of` 写死了 0~10 对的重载方法（`of()`、`of(k,v)`、`of(k,v,k,v)`……最多 10 对），**没有 11 个参数的版本，所以编译器直接找不到方法**。

**超过 10 对怎么办？用 `Map.ofEntries()`：**

```java
Map<String, Integer> big = Map.ofEntries(
    Map.entry("k1", 1),
    Map.entry("k2", 2),
    // ... 想写多少写多少
    Map.entry("k11", 11)
);
// ✅ 11 对，没问题
```

**`Map.ofEntries` 用 `Map.entry(key, value)` 一个个往里塞，没有数量限制。**

## 5. JDK 8 的老办法：Collections.unmodifiableXxx

> JDK 9 之前没有 `List.of`，只能用这个。

```java
List<String> list = new ArrayList<>(List.of("a", "b"));

// 包一层"不可修改的外壳"
List<String> unmodList = Collections.unmodifiableList(list);
Set<String>  unmodSet  = Collections.unmodifiableSet(new HashSet<>(list));
Map<String, Integer> unmodMap = Collections.unmodifiableMap(new HashMap<>());
```

**效果**：通过 `unmodList` 改不了：

```java
unmodList.add("c");   // ❌ UnsupportedOperationException
```

## 6. 视图 vs 拷贝（最容易懵的一节）

**`Collections.unmodifiableList` 和 `List.copyOf` 看起来都是"不可变"，但有一个致命区别。**

### 6.1 unmodifiableList 是"视图"——原集合变了它也变

```java
List<String> mutable = new ArrayList<>(List.of("a", "b"));
List<String> view = Collections.unmodifiableList(mutable);

System.out.println(view);      // [a, b]

mutable.add("c");              // 改原集合（view 拦不住）
System.out.println(view);      // [a, b, c]   ← 它也变了！
```

**你没法通过 `view` 改，但别人可以改原集合，然后 `view` 就跟着变。**

### 6.2 copyOf 是"拷贝"——原集合变了不影响

```java
List<String> src = new ArrayList<>(List.of("a", "b"));
List<String> copy = List.copyOf(src);

src.add("c");
System.out.println(copy);      // [a, b]   ← 不受影响
```

### 6.3 对比表

| | `Collections.unmodifiableList` | `List.copyOf` / `List.of` |
|---|---|---|
| 本质 | **视图**（外壳） | **独立拷贝** |
| 原集合变化 | **会跟着变** | 不受影响 |
| 通过它改 | 不行 | 不行 |
| 线程安全 | ⚠️ 原集合被改就不安全 | ✅ 安全 |
| 推荐度 | 老代码用 | **新代码用这个** |

**一句话**：**真正的线程安全、真正的不可变，用 `List.of` / `List.copyOf`；`Collections.unmodifiableXxx` 只是个"只读窗口"。**

## 7. 坑：不可变是"浅"的

**不可变集合只能保证"集合结构不变"，但元素本身如果是可变对象，照样能改。**

```java
List<StringBuilder> list = List.of(new StringBuilder("a"), new StringBuilder("b"));

list.get(0).append("!");     // ✅ 可以！改的是元素内部
System.out.println(list);    // [a!, b]   ← 内容变了

list.set(0, new StringBuilder("x"));   // ❌ 这个不行，换元素 = 改结构
```

**结论**：
- **不能换元素、不能增删**（集合结构被锁死）
- **但元素对象内部的状态可以改**（如果元素本身可变）

**要真正"完全不可变"，元素也必须是不可变对象**（`String`、`Integer`、`record` 等）。

## 8. 底层实现（了解即可）

`List.of()` 返回的**不是** `ArrayList`，而是 JDK 内部的专用类：

```java
List.of("a").getClass().getName();      // java.util.ImmutableCollections$List12
Set.of("a").getClass().getName();       // java.util.ImmutableCollections$Set12
Map.of("a", 1).getClass().getName();    // java.util.ImmutableCollections$Map1
List.of().getClass().getName();         // java.util.ImmutableCollections$ListN
```

**这些类按元素个数做了特化**（1~2 个用 `List12`，更多用 `ListN`），目的是**省内存、读得快**。

**你不用管类名，只要知道它不是 ArrayList 就行**——所以 `instanceof ArrayList` 会返回 `false`。

## 9. 不可变集合能干什么（能用的操作）

**不能写，但能读、能遍历、能流操作：**

```java
List<Integer> nums = List.of(3, 1, 2);

nums.get(0);                       // 3        按下标读
nums.size();                       // 3
nums.contains(1);                  // true
nums.indexOf(2);                   // 2

nums.forEach(n -> System.out.println(n));       // 遍历
for (int n : nums) { }                          // 增强 for
nums.stream().sorted().toList();                // 流操作 → [1, 2, 3]

nums.equals(List.of(3, 1, 2));                 // true
new ArrayList<>(List.of("a")).equals(List.of("a"));  // true 跨实现也能比
```

**总结**：**读、查、遍历、转流，都行；增、删、改、清空，都不行。**

## 10. 常见用法场景

### 场景 1：当常量

```java
public class Config {
    public static final List<String> ALLOWED_EXT = List.of("png", "jpg", "gif");
    public static final Map<String, Integer> LIMITS = Map.of("maxSize", 10, "maxCount", 100);
}
```

### 场景 2：方法返回内部数据，防止被改

```java
public class User {
    private final List<String> roles;

    public User(List<String> roles) {
        this.roles = List.copyOf(roles);      // 拷贝并锁死
    }

    public List<String> getRoles() {
        return roles;                          // 返回出去也改不了
    }
}
```

### 场景 3：方法参数默认值

```java
public void work(List<String> tasks) {
    if (tasks == null) tasks = List.of();      // 不可变的空列表当默认值
}
```

### 场景 4：多线程共享数据

```java
static final List<String> SHARED = List.of("a", "b", "c");
// 多个线程同时读，不用加锁
```

## 11. 想要"可变副本"怎么办

**不可变集合改不了，但可以复制成一个新的可变集合：**

```java
List<String> fixed = List.of("a", "b");

// 拷贝成 ArrayList（可变）
List<String> mutable = new ArrayList<>(fixed);
mutable.add("c");
System.out.println(mutable);     // [a, b, c]

System.out.println(fixed);       // [a, b]   ← 原集合不受影响
```

**这是标准套路**：**`new ArrayList<>(不可变集合)`**。

## 12. 一页速查表

### 创建

| 想要 | 写法 |
|---|---|
| 空 List | `List.of()` |
| 空 Set | `Set.of()` |
| 空 Map | `Map.of()` |
| 带元素 List | `List.of("a", "b")` |
| 带元素 Set | `Set.of("a", "b")` |
| 带元素 Map | `Map.of("a", 1, "b", 2)` |
| 超过 10 对的 Map | `Map.ofEntries(Map.entry(k, v), ...)` |
| 拷贝已有集合 | `List.copyOf(src)` / `Set.copyOf(src)` / `Map.copyOf(src)` |
| JDK 8 写法 | `Collections.unmodifiableList(list)` |

### 能做什么 / 不能做什么

| 操作 | 不可变集合 |
|---|---|
| `get` / `size` / `contains` / `indexOf` | ✅ 可以 |
| `forEach` / for-each / `stream` | ✅ 可以 |
| `add` / `set` / `remove` / `clear` | ❌ 抛 `UnsupportedOperationException` |
| 元素是 `null` | ❌ 抛 `NullPointerException` |
| `Set.of` / `Map.of` 有重复 | ❌ 抛 `IllegalArgumentException` |

### 视图 vs 拷贝

| | `Collections.unmodifiableList` | `List.copyOf` |
|---|---|---|
| 原集合改 | 跟着变 | 不变 |
| 线程安全 | ❌ | ✅ |

## 13. 常见错误速查

| ❌ 错法 | ✅ 对法 | 后果 |
|---|---|---|
| `List.of(...).add(...)` | 需要可变就 `new ArrayList<>(...)` | `UnsupportedOperationException` |
| `List.of("a", null)` | 确保没有 null | `NullPointerException` |
| `Set.of("a", "a")` | 去掉重复 | `IllegalArgumentException` |
| `Map.of` 传 11 对 | `Map.ofEntries(...)` | **编译错误** |
| 以为 `unmodifiableList` 是拷贝 | 用 `List.copyOf` 才是拷贝 | 原集合一变，视图跟着变 |
| 以为不可变集合"完全不能改" | 元素本身可变的话能改元素内部 | 数据被意外修改 |
| 以为 `List.of` 返回 `ArrayList` | 是 `ImmutableCollections$ListN` | `instanceof ArrayList` 为 false |
| 在 `List.of` 里放可变对象 | 放 `String`/`Integer` 等不可变对象 | 元素被改你不知道 |

```java
import java.util.*;

// ① 感受一下写操作全被禁
List<String> list = List.of("a", "b");
try { list.add("c"); } catch (UnsupportedOperationException e) { System.out.println("add 被禁"); }
try { list.set(0, "z"); } catch (UnsupportedOperationException e) { System.out.println("set 被禁"); }

// ② null 和重复的异常
try { List.of("a", null); } catch (NullPointerException e) { System.out.println("null 被禁"); }
try { Set.of("a", "a"); } catch (IllegalArgumentException e) { System.out.println("重复被禁"); }

// ③ 视图 vs 拷贝
List<String> src = new ArrayList<>(List.of("a", "b"));
List<String> view = Collections.unmodifiableList(src);
List<String> copy = List.copyOf(src);
src.add("c");
System.out.println("view: " + view + "  ← 跟着变了");
System.out.println("copy: " + copy + "  ← 没变");

// ④ 转成可变副本
List<String> mutable = new ArrayList<>(List.of("a", "b"));
mutable.add("c");
System.out.println("可变副本: " + mutable);

// ⑤ 超过 10 对的 Map
Map<String,Integer> big = Map.ofEntries(
    Map.entry("k1", 1), Map.entry("k2", 2), Map.entry("k3", 3),
    Map.entry("k4", 4), Map.entry("k5", 5), Map.entry("k6", 6),
    Map.entry("k7", 7), Map.entry("k8", 8), Map.entry("k9", 9),
    Map.entry("k10", 10), Map.entry("k11", 11)
);
System.out.println("11 对: " + big.size());
```

## 记忆口诀

> **List.of 创建好后，增删改全抛异常；**
> **null 和重复直接炸，Map.of 最多十对整；**
> **超过十对用 ofEntries，entry 一个个塞；**
> **unmodifiable 是视图，copyOf 才是拷贝；**
> **不可变只是浅的，元素自己还能变。**
