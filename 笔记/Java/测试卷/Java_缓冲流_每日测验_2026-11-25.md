## 四、代码分析题（3 小题，每题 6 分，共 18 分；写出运行结果/现象）

**26.** 文件 `lines.txt` 内容为三行：`第一行`、`第二行`、`第三行`（每行末尾有换行）。写出输出结果。

```java
try (BufferedReader br = new BufferedReader(new FileReader("lines.txt"))) {
    String line;
    int i = 0;
    while ((line = br.readLine()) != null) {
        i++;
        System.out.println(i + ":" + line);
    }
    System.out.println("共" + i + "行");
}
```

**27.** 写出两次打印的结果（文件第一次打印时还未关闭流）。

```java
File f = new File("out.txt");
BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(f));
bos.write("hello".getBytes());
System.out.println(f.length());
bos.close();
System.out.println(f.length());
```

**28.** 出师表练习里，目录下有 `1.txt`、`2.txt`、`10.txt` 三个文件。写出两行输出结果。

```java
String[] names = {"1.txt", "2.txt", "10.txt"};
Arrays.sort(names);
System.out.println(Arrays.toString(names));

Arrays.sort(names, (a, b) ->
        Integer.parseInt(a.replace(".txt", "")) - Integer.parseInt(b.replace(".txt", "")));
System.out.println(Arrays.toString(names));
```
