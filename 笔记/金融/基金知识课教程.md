# 基金知识课教程（12 课路线图）

> 用途：学习路线图 · 定位：系统学，不是零散听
> 前置：[[投资认知地基教程]]（第 0 课，没读先读）
> 配套实盘：`~/dsh-work/ fund/`（工作台，含持仓数据，**不公开**）

---

## 0. 这套课怎么用

**一句话**：每课配当周真实数据 + 一道判断题，判断题答案在下一课揭晓。

### 三条纪律

1. **顺序不可跳。** 第 2 课（净值）没搞懂之前不讲第 8 课（估值），否则一定会算错收益。
2. **每课配当周真实数据。** 不脱离实盘讲理论——抽象概念记不住，真实数字才记得住。
3. **判断题答不上来 = 那一课重学。** 不是考试，是自查。

### 建议节奏

| 方式 | 节奏 | 适合 |
| --- | --- | --- |
| **每周一课** ⭐ | 12 周学完 | 想扎实 |
| 两课/周 | 6 周学完 | 想快速上手 |
| 按需学 | 遇到什么学什么 | 时间碎 |

> 推荐每周一课。因为它配的是"当周真实数据 + 一周才能验证的判断题"。
> 压缩节奏，你只是在"看课"，不是在"学"。

# 第一层：搞懂你在买什么

## 第 1 课 · 基金到底是什么

**要解决的问题**：能说清"我买的这个东西，钱去哪了，什么时候能拿回来"。

| 核心概念 | 一句话 |
| --- | --- |
| 场外 vs 场内 | 蚂蚁财富买的是场外，不能像股票即时成交 |
| 申赎时间线 | 申购 → 确认 → 持有 → 赎回，T+1 才确认 |
| A 类 vs C 类 | A 收申购费（一次），C 收销售服务费（按年）。<1 年选 C，>1 年选 A |
| 谁在管你的钱 | 基金公司管、托管银行存、蚂蚁只是渠道（不碰你的钱） |

**常见坑**：以为"买了就生效" → 实际 T+1 才确认，当天涨跌跟你无关

**判断题**：周五下午 3 点前买入，什么时候确认份额？按哪一天的净值算？

---

## 第 2 课 · 净值的三个陷阱 ⚠️

**要解决的问题**：自己能算出真实收益，不被"单位净值"骗。

> **这是全套课最重要的一课。** 算错收益率，后面所有决策都是错的。
> 而且这个错误极其隐蔽——数字看起来很正常。

| 核心概念 | 一句话 |
| --- | --- |
| 单位净值 vs 累计净值 | 算长期收益必须用累计净值 |
| 分红 | 分红当天净值会"跳水"，不是跌了 |
| 拆分/份额折算 | 净值腰斩不代表跌了，直接算 pct_change 会得到假暴跌 |

**核心公式**：

```
✅ 真实收益率 = (期末累计净值 ÷ 期初累计净值) - 1
❌ 错误做法   = (期末单位净值 ÷ 期初单位净值) - 1
```

**真实案例**：某 ETF 在 2012-05-11 做份额折算（1:0.3709），直接算涨跌幅会得到一个巨大的伪涨幅。

**常见坑**：在蚂蚁财富看到"收益率"就信，从不自己验算

**判断题**：某基金单位净值从 2.0 跌到 1.0，同时每份分红 1.0 元。你亏了还是赚了？

---

## 第 3 课 · 基金分类地图

**要解决的问题**：看到一只基金的名字，30 秒内判断它大概是什么风险收益特征。

| 分类维度 | 类别 |
| --- | --- |
| 按资产 | 股票型 / 混合型 / 债券型 / 货币型 / FOF |
| 按策略 | 主动型 / 指数型（被动）/ 增强指数 |
| 按市场 | A股 / QDII（海外）/ 港股通 |
| 特殊结构 | ETF / ETF 联接 / LOF |

**新手最该知道的三个品类**：宽基指数、纯债、货币

**常见坑**：看到"稳健""精选""价值"这种词就以为是低风险。
（名字随便起，要看合同里的**投资范围和仓位限制**）

**判断题**："XX 稳健增利混合"这个名字能告诉你是低风险吗？

---

## 第 4 课 · 费率的完整账本

**要解决的问题**：能算出一笔买卖的完整成本，知道哪些费用会吃掉收益。

| 费用 | 什么时候收 | 典型值 | 谁拿走 |
| --- | --- | --- | --- |
| 申购费 | 买入时 | 1.5%，平台常打 1 折 ≈ 0.15% | 销售渠道 |
| 赎回费 | 卖出时 | **7 天内 1.5%**，之后按持有期递减 | 基金资产 |
| 管理费 | 每天从净值扣 | 1.5%/年（指数约 0.5%） | 基金公司 |
| 托管费 | 每天从净值扣 | 0.25%/年 | 托管银行 |
| 销售服务费 | 每天从净值扣（C 类有） | 0.2-0.8%/年 | 销售渠道 |

**关键认知**：管理费/托管费/销售服务费**已经在净值里扣了**，你不会额外付，但它确实在侵蚀收益。

**7 天赎回费 1.5% 的杀伤力**：1000 元拿进拿出一次 = 亏 15 元。基金要先涨 1.5% 你才回本。

**常见坑**：只看申购费打折，忽略赎回费；频繁交易把收益全交给手续费

**判断题**：C 类基金没有申购费，是不是一定比 A 类划算？

# 第二层：判断好坏

## 第 5 课 · 收益指标：年化怎么算才不是骗人

**要解决的问题**：看懂一只基金的收益数据，不被数字游戏骗。

| 核心概念 | 一句话 |
| --- | --- |
| 累计 vs 年化 | 同一只基金两个数字能差很多倍 |
| 算术 vs 几何平均 | 复利必须用几何平均 |
| 时间维度 | 近 1 年 / 3 年 / 5 年 / 成立以来，缺一不可 |

**年化收益的欺骗性**：成立 2 个月翻倍 → 年化 400%，毫无意义。

**常见坑**：被"近一年收益 120%"吸引，没看成立时间只有 8 个月

**判断题**：一只基金近 1 年 +50%；另一只近 1 年 +20% 但近 3 年年化 +18%。哪只更可能是好基金？

---

## 第 6 课 · 风险指标：回撤、波动率、夏普

**要解决的问题**：知道"能不能拿得住"比"收益高不高"更重要。

| 指标 | 含义 | 为什么重要 |
| --- | --- | --- |
| 最大回撤 | 从最高点跌到最低点跌多少 | **这是你真实会经历的痛苦** |
| 波动率 | 净值波动剧烈程度 | 决定你睡不睡得着 |
| 夏普比率 | 每承担 1 单位波动，换来多少超额收益 | 性价比 |
| 卡玛比率 | 年化收益 ÷ 最大回撤 | 更直观的性价比 |

**核心认知**：收益是表象，回撤才决定你能否拿得住。
一只年化 15% 但最大回撤 40% 的基金，大部分人在 -30% 时割肉了，根本吃不到那 15%。

**常见坑**：只看收益排行榜，从不看回撤

**判断题**：两只基金年化都是 20%，A 最大回撤 15%，B 最大回撤 45%。你实际拿到 20% 的概率哪个高？

---

## 第 7 课 · 主动 vs 被动：为什么新手该从指数开始

**要解决的问题**：明白"选基金经理"对新手是不公平的游戏。

| | 指数基金 | 主动基金 |
| --- | --- | --- |
| 依赖 | 跟指数走，不赌经理 | 依赖基金经理 |
| 费率 | 低（约 0.5%） | 高（约 1.5%） |
| 风险 | 承担市场风险 | 经理风险 + 市场风险 |

**业绩可持续性**：去年冠军今年垫底，是常态。

**核心认知**：指数基金是"买国运/买行业"，主动基金是"赌人"。
在你无法判断人的时候，别赌人。

**常见坑**：追去年的冠军基金

**判断题**：一只基金去年排名第 1，今年买它，期望收益会比平均高吗？

---

## 第 8 课 · 估值：为什么 PE 低可能是陷阱

**要解决的问题**：看懂估值分位，分得清"便宜"和"盈利崩塌"。

| 核心概念 | 一句话 |
| --- | --- |
| PE | 价格 ÷ 盈利 |
| PB | 价格 ÷ 净资产 |
| 历史分位 | 现在的值在过去 N 年里排第几 |
| **分母陷阱** | 盈利下滑时 PE 会自然变低，**这不叫便宜** |

**真实案例（2026-11-06 实测数据）**：

```
沪深300：PE 分位 68%，PB 分位 22%  ← 相差 46 个百分点，信号打架
创业板：PE 分位 12%，PB 分位 22%    ← 看着极便宜，但当天跌 3.96%
上证50：PE 分位 83%，PB 分位 45%    ← 也打架
```

**关键问题**：创业板 PE 分位 12%，到底是"便宜"，还是"盈利崩塌导致的分母效应"？
这一课就是教你分辨这两个。

**常见坑**：看到"PE 历史最低"就重仓

**判断题**：某行业 PE 从 30 跌到 10，是因为股价跌了 2/3，还是因为盈利涨了 2 倍？怎么验证？

# 第三层：做决策

## 第 9 课 · 行业与风格：轮动是怎么发生的

**要解决的问题**：看懂板块涨跌在说什么，不去赌单一行业。

| 核心概念 | 一句话 |
| --- | --- |
| 四类风格 | 周期 / 成长 / 价值 / 红利 |
| 轮动驱动 | 利率、政策、景气度、资金 |
| 板块温度 | 涨跌家数比看市场情绪 |

**真实案例（2026-11-06）**：
```
496 个板块中 443 个下跌
涨幅榜：视频媒体 +6.25%、种子 +4.64%、养殖 +3.18%（防御）
跌幅榜：印制电路板 -5.86%、元件 -5.13%（科技杀跌）
```
→ 这说明资金在避险，不是基本面崩了。

**常见坑**：看到某行业连涨一周就追进去，正好接最后一棒

**判断题**：今天 443/496 板块下跌，涨幅榜是"种子、养殖、运营商"。这说明资金在做什么？

---

## 第 10 课 · 定投与分批：微笑曲线与它的失效场景

**要解决的问题**：知道定投什么时候有效、什么时候无效。

| 概念 | 一句话 |
| --- | --- |
| 定投原理 | 摊薄成本，但**只在先跌后涨时有效** |
| 微笑曲线 | 先跌后涨 → 定投赢 |
| 哭泣曲线 | 单边上涨 → 一次性买入赢 |
| 止盈策略 | 目标收益率 / 回撤 / 估值 |

**核心认知**：定投是"降低择时压力"的工具，不是"提高收益"的工具。

**常见坑**：以为定投一定赚钱

**判断题**：如果市场未来 3 年单边上涨，定投和一次性买入哪个收益高？

---

## 第 11 课 · 组合与再平衡：1000 元怎么分配

**要解决的问题**：知道怎么分配，以及小本金的现实边界。

| 核心概念 | 一句话 |
| --- | --- |
| 相关性 | 要买走势不同步的东西 |
| 仓位管理 | 股债比例、单品类上限 |
| 再平衡 | 什么时候调、怎么调 |

**参考结构（理解用，不是推荐）**：
```
进攻仓 60-70%：宽基指数
防守仓 20-30%：纯债 / 短债
现金 10%     ：机会来了才用
```

**小本金的现实**：分 3-4 只就是极限。再分散没有意义，因为每笔手续费占比上升。

**常见坑**：买 8 只基金，以为分散了风险，实际买了个"平均"，还多付 8 份手续费

**判断题**：1000 元买 6 只基金，和买 2 只，风险真的更低吗？

---

## 第 12 课 · 行为偏差：决定 90% 盈亏的其实是这个

> **这是全课最重要的一课。** 它解释了你为什么"知道很多道理却还是亏钱"。

| 偏差 | 表现 | 后果 |
| --- | --- | --- |
| **损失厌恶** | 亏 100 的痛苦 ≈ 赚 200 的快乐 | 死扛亏损、过早止盈 |
| **追涨杀跌** | FOMO 与恐慌 | 高买低卖 |
| **锚定效应** | 以买入价为锚 | 不肯承认判断错误 |
| **确认偏误** | 只看支持自己的信息 | 越错越自信 |
| **过度自信** | 牛市里最危险 | 加杠杆、满仓 |

**如何对抗**：
1. 写决策日志（`journal/decisions.md`）—— 让"当时的理由"留证据
2. 强制反方观点（辩论台）—— 让空头必须发言
3. 定量风控红线 —— 让情绪没有发挥空间

**判断题**：你买入后跌了 10%，第一反应是"补仓摊薄"还是"复核买入理由"？哪个更理性？
