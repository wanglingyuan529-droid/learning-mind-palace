# 投资认知地基教程（小白版）

> 用途：学习笔记 · 定位：讲得细、面向刚入门
> 覆盖：基金知识课 **第 0 课**（学前必读，不接受这一课，后面全白学）
> 文中数据均为 2026-11-06 核实，来源标在文末

---

## 0. 一句话认识

**你不需要预测未来才能赚钱。** 你需要的是：买得便宜、成本够低、拿得够久、不犯大错。
这四样里，没有一样需要预测。

| 概念 | 解决什么问题 | 类比 |
| --- | --- | --- |
| 安全边际 | 算错了也不死 | 买保险柜，不买彩票 |
| 概率思维 | 不追求确定，追求赔率 | 德州扑克高手不猜下一张牌 |
| 可拒绝性 | 你能选择不下注 | 投资是唯一允许你永远站着不挥棒的游戏 |
| 复利 | 时间是唯一免费的杠杆 | 滚雪球，要足够长的坡 |

---

## 1. 先破一个误解：赚钱 ≠ 预测得准

很多人（包括我一开始）都以为：
> 投资高手 = 能算准涨跌的人

**这个理解是错的。** 巴菲特恰恰是以**不预测**著称的。

他是格雷厄姆的学生。格雷厄姆的核心思想不是"算准未来"，而是：

> **在价格远低于价值时买入，这样即使你算错了，也不会死。**

这叫**安全边际**（margin of safety）。它不要求你预测正确，只要求你**买得足够便宜**。

巴菲特反复讲过两件事：

1. **他不看宏观预测。** 他说过，我们不考虑政治和经济预测，那是很多投资者和商人的"昂贵消遣"。
2. **预测能告诉你预测者的事，但告诉不了你未来的事。**

所以下次有人跟你说"机器都预测不了，人凭什么赚钱"，你可以回一句：
> **巴菲特也不预测，他照样赚了。**

---

## 2. 巴菲特的钱从哪来：拆开看

要判断"技术多还是运气多"，得先把他的收益来源拆开，分成**可学的**和**不可复制的**。

### 2.1 可学的（方法）

| 能力 | 通俗解释 |
| --- | --- |
| **能力圈** | 只投自己能看懂的，不懂就不碰 |
| **商业模式判断** | 这家公司有没有护城河？能不能随意涨价？管理层靠不靠谱？ |
| **安全边际** | 价格远低于价值时才买，给自己留余地 |
| **长期持有** | 买了好公司就不动，不被市场逼着卖 |
| **逆向** | 别人恐惧时贪婪，别人贪婪时恐惧 |

### 2.2 不可复制的（运气 + 结构优势）

| 优势 | 为什么普通人拿不到 |
| --- | --- |
| **保险浮存金** | 伯克希尔有大量"先收保费、后赔付"的钱，等于**零成本甚至负成本杠杆**。普通人借钱要付 4-6% 利息 |
| **出生时点** | 1930 年生，刚好赶上美国世纪。他自己说"我中了卵巢彩票" |
| **时代红利** | 战后美国经济增长，这是他收益的底层地基 |
| **活得久** | 95 岁。复利需要时间：年化 20% 坚持 60 年 = 5.6 万倍；坚持 20 年 = 38 倍 |

### 2.3 关键数字对比

| | 年化收益 |
| --- | --- |
| 伯克希尔（1965-2021） | 约 **20.1%** |
| 标普500 全收益（同期） | 约 **10.5%** |

**但要注意**：这 20.1% 是**用保险浮存金加了杠杆的**。去掉杠杆，会低很多。

### 2.4 所以准确的答案是

> 他的**方法**里，技术占主导（可学）。
> 他的**结果**里，有大量运气和结构优势（不可复制）。
>
> 他的方法不能把你变成他，因为你拿不到他的结构优势。
> **但你不需要变成他。你只需要不亏钱。**

## 3. 赌和投资的真正区别

这是本课最重要的一段。

赌博和投资的区别，**不在"是否承担不确定性"**——两者都承担。
区别在四个地方：

| | 赌博 | 投资 |
| --- | --- | --- |
| **期望值** | 负的（赌场抽水） | 可以正的（企业创造价值） |
| **能否拒绝** | 进了赌场就得上桌 | **你可以永远不下注** |
| **赔率选择** | 规则定死 | 可以只在赔率高时出手 |
| **时间** | 每局独立，无复利 | 有复利 |

### 3.1 最关键的是"可拒绝性"

赌场里你不能说"这局我不玩"。
但投资里，**你可以一辈子不买任何一只基金，这不需要任何成本**。

> **"不做决定"本身就是一个决定，而且经常是最优决定。**

巴菲特打过一个棒球比喻（借自 Ted Williams 的击球区理论）：
> 投资最大的优势是**没有强制挥棒**。你可以站着，等一个"好球"再挥。

赌场不给你这个权利。这就是本质区别。

### 3.2 第二个区别：你要预测的是"分布"，不是"点"

- 扑克高手**不预测下一张牌**，他看底池赔率决定要不要跟注
- 保险公司**不预测你什么时候死**，但能稳定盈利
- 这就是**概率思维**和**预测思维**的区别

所以结论是：

> 赌博 = **没有优势的押注**
> 投资 = **有优势时下注，没优势时等待**

"无法预测" ≠ "赌博"。**"没有优势还下注"才是赌博。**

## 4. 那场十年赌局（最有意思的不是结果）

### 4.1 赌的是什么

2007 年，巴菲特以 100 万美元下注：
**标普500 指数基金，10 年后能不能赢过 5 只对冲基金的组合。**

对冲基金经理 Ted Seides 应战。赌期：2008-01-01 到 2017-12-31。

### 4.2 结果

| | 累计收益 |
| --- | --- |
| 标普500 指数基金 | **+125.8%** |
| 5 只对冲基金组合 | **+36.3%** |

巴菲特完胜。

### 4.3 但真正的关键细节在这里

> **赛前，巴菲特估计自己获胜的概率大约只有 60%。**
> 而西德斯认为自己的胜率有 85%。

这说明三件事：

1. **即使是最有把握的判断，专业投资者也只给 60% 概率。** 他说不出"一定赢"。
2. **他的赢不是靠"确定"，是靠"赔率"**：60% 概率，赢了收益大，输了损失有限 → 正期望值。
3. **他敢在 60% 上下注，因为他能承受那 40% 的错。** 这就是风控的意义。

### 4.4 业余 vs 专业的分水岭

| | 问的问题 | 要的东西 |
| --- | --- | --- |
| 业余 | "这个会不会涨？" | 确定 |
| **专业** | "**我对了赚多少、错了亏多少，值不值得下注？**" | **赔率** |

## 5. 那么，无法预测该怎么办？

### 5.1 你能控制的只有三件事

| 能控制 | 为什么重要 | 数字举例 |
| --- | --- | --- |
| **成本（费率）** | 每年悄悄吃掉你的收益 | 年费 1.5% vs 0.5%，10 年后差约 10% |
| **行为（不追涨杀跌）** | 这是绝大多数人亏钱的真因 | 一次 7 天内赎回 = **-1.5%** |
| **时间（持有长度）** | 复利需要时间，时间是唯一免费的杠杆 | 年化 8%，10 年 2.16 倍，20 年 4.66 倍 |

### 5.2 你控制不了的

> 明天涨跌、政策变化、黑天鹅、别人的情绪。

**策略的本质：把全部精力放在能控制的事上。**

### 5.3 对小本金的具体意义

| 做法 | 为什么 |
| --- | --- |
| 低成本宽基指数 | 不赌经理，费率低，不用判断人 |
| 分批或定投 | 降低"一次买在最高点"的伤害 |
| 不频繁交易 | 避开 1.5% 惩罚，这是最确定能省下的钱 |
| 至少拿 1-3 年 | 时间是你的朋友 |
| 目标不是赚大钱 | 是**建立不亏钱的习惯** |

> 本金亏完也就那么多，这是学费上限。
> 但如果十年后还不知道"为什么亏"，这学费就白交了。

## 6. 常见坑

| 坑 | 现象 | 正确做法 |
| --- | --- | --- |
| **把"不确定"当成"赌博"** | 觉得反正都是赌，那就随便赌 | 区分"有优势的下注"和"没优势的下注" |
| **追求确定性** | 到处找"能预测的人"、找"必涨"的票 | 问赔率，不问确定性 |
| **迷信大师** | 以为学巴菲特的方法就能变成巴菲特 | 学方法，但要认清他的结构优势你拿不到 |
| **以为不预测就不能赚钱** | 觉得不预测就只能存银行 | 指数基金 + 长期 + 低成本，本身就是不预测的赚钱方式 |
| **只看收益不看回撤** | 被"年化 20%"吸引 | 回撤 40% 的基金，你大概率拿不住那 20% |

## 一句话总结

> **避开明显的蠢事，就已经跑赢大多数人了。**
> 而这个工作台（`fund/`）的价值，不在"告诉你买什么"，在**"阻止你做明显的蠢事"**。
