## 怎么加新词

1. 当天日记的「📝 生词」表先随手记，不用查音标。
2. 周末集中整理到这里：补音标、找 Java 语境里的真实用法。
3. 不熟的标 🔥，背会了改成 ✅。**🔥 超过 20 个就不要再加新词了**，先清库存。
