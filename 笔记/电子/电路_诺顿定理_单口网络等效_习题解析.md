# 用诺顿定理求电流 i（单口网络等效 + 分流公式）

> 这道题的"坑"不在计算，而在读图：电路画成电桥的样子，实际是五只电阻并联在同一对节点上。看破这点，后面就是诺顿定理的标准三步。

## 答案速览

| 填空 | 求解量 | 答案 |
| :--: | --- | :--: |
| 1 | $I_{SC}$ | **$3\ \text{A}$**（方向由节点 P 流向节点 N，与图中 $i$ 同向） |
| 2 | $R_0$ | **$10\ \Omega$** |
| 3 | $i$ | **$1\ \text{A}$**（方向向下，与图中箭头一致） |

---

## 一、题目

用诺顿定理求图示电路的电流 $i$。求解步骤：

1. 求除了 $20\ \Omega$ 电阻以外的单口网络的诺顿等效电路：

$$I_{SC}=\ ?\ \text{A};\qquad R_0=\ ?\ \Omega$$

2. 利用分流公式求得电流

$$i=\ ?\ \text{A}$$

已知：$120\ \text{V}$ 直流电压源（上正下负）、$40\ \Omega$、$30\ \Omega$、$60\ \Omega$、$80\ \Omega$（斜置）、$80\ \Omega$（竖直）、$20\ \Omega$（负载，电流 $i$ 向下）。

## 二、先把电路读对：它看着像电桥，其实是五只并联

把节点按要求归纳，原图上两个"隐藏"的节点合并如下：

| 图中位置 | 归并后 | 依据 |
| --- | --- | --- |
| 左上：$40\ \Omega$ 右端、$30\ \Omega$ 顶端 | 节点 **P** | 顶部导线一直连到右上 $80\ \Omega$（竖）的上端，中间没有断开 |
| 右下：$80\ \Omega$（竖）的下端、空心端子处 | 节点 **N** | 底部导线从电源负极出发，经 $30\ \Omega$ 底端、$60\ \Omega$ 斜臂底端，一路连到 $20\ \Omega$ 的下端 |

两条斜臂的接法：

- $80\ \Omega$（斜）从左上（P）连到右下（N）；
- $60\ \Omega$（斜）从左下（N）连到右上（P）。

两斜臂在图中十字交叉，**交叉点没有实心节点圆点**，所以只是空间上交叉，彼此**不相连**。

于是各元件的真实连接关系：

| 元件 | 两端节点 |
| --- | --- |
| $120\ \text{V}$ 电压源 | 正极经 $40\ \Omega$ 接 P，负极接 N |
| $40\ \Omega$ | 电源正极与 P 之间（串联在电源支路） |
| $30\ \Omega$ | P–N |
| $60\ \Omega$ | P–N（斜臂） |
| $80\ \Omega$（斜） | P–N（斜臂） |
| $80\ \Omega$（竖） | P–N |
| $20\ \Omega$ | P–N，电流 $i$ 由 P 向下流到 N |

所以：**P–N 之间并着 $30\ \Omega$、$60\ \Omega$、$80\ \Omega$、$80\ \Omega$、$20\ \Omega$ 五只电阻**，$40\ \Omega$ 与电源串联后接到 P–N 上。画成母线形式就是：

```
 120V(+) ─[40 Ω]─ P ─┬───────┬───────┬───────┬───────┬──────┐
                     │       │       │       │       │      │
                   30 Ω    60 Ω    80 Ω    80 Ω    20 Ω     │
                     │       │       │       │       │ ↓i   │
 120V(−) ──────── N ─┴───────┴───────┴───────┴───────┴──────┘
```

一句话：这就是"一个 $120\ \text{V}$ 电压源串 $40\ \Omega$，再接五只并联电阻"的电路。

## 三、第 1 步：求诺顿等效电路（填空 1、2）

### 3.1 求短路电流 $I_{SC}$

把 $20\ \Omega$ 支路去掉，让 P、N 之间只留 $30\ \Omega$、$60\ \Omega$、$80\ \Omega$、$80\ \Omega$，再把 **P–N 端口短路**。

短路后 $V_{PN}=0$，这四只电阻两端电压为零，全部被短接线旁路、没有电流流过；短路电流只能由电源支路提供：

$$I_{SC}=\frac{120}{40}=3\ \text{A}$$

方向：由 P 经短接线流向 N（即向下），与图中 $i$ 的箭头同向。

> 注意：不是 $\dfrac{120}{40+(\text{并联部分})}$。那是接了负载后的工作状态，短路状态下并联的电阻被短接，不参与通电。

### 3.2 求诺顿等效电阻 $R_0$

把电压源置零（用导线代替，即电源两端短接），**从 P–N 端口看进去**：

与 P–N 直接相接的一共有五只电阻——$30\ \Omega$、$60\ \Omega$、$80\ \Omega$、$80\ \Omega$，以及 **$40\ \Omega$**（它的另一端原来接电源正极，电源置零后就连到了 N）。所以

$$\frac{1}{R_0}=\frac{1}{40}+\frac{1}{30}+\frac{1}{60}+\frac{1}{80}+\frac{1}{80}$$

$$=0.025+0.03333+0.01667+0.0125+0.0125=0.1\ \text{S}$$

$$R_0=\frac{1}{0.1}=10\ \Omega$$

也可以先化简再算：

$$30\parallel 60=20\ \Omega,\qquad 80\parallel 80=40\ \Omega$$
$$R_0=40\parallel 20\parallel 40=\left(\frac{1}{40}+\frac{1}{20}+\frac{1}{40}\right)^{-1}=10\ \Omega$$

### 3.3 诺顿等效电路

```
   P ○──┬──────────────┬──
        │              │
        │ (3 A ↓)    [10 Ω]
        │              │
   N ○──┴──────────────┴──
```

即 $I_{SC}=3\ \text{A}$ 的理想电流源（箭头由 P 向下指向 N）与 $R_0=10\ \Omega$ 并联。

## 四、第 2 步：分流公式求 $i$（填空 3）

把 $20\ \Omega$ 负载接回 P–N 端口，$3\ \text{A}$ 的电流源在 $R_0$ 与 $20\ \Omega$ 之间分流（并联分流公式，电阻越大分得越少）：

$$i=I_{SC}\cdot\frac{R_0}{R_0+20}=3\cdot\frac{10}{10+20}=1\ \text{A}$$

方向：由 P 流向 N（向下），与图中箭头一致，取正值。

> 填：$I_{SC}=3$，$R_0=10$，$i=1$。

## 五、验证（三种口径都对得上）

**（1）戴维南口径。** $U_{OC}=I_{SC}R_0=3\times 10=30\ \text{V}$，接 $20\ \Omega$：

$$i=\frac{30}{10+20}=1\ \text{A}\quad\checkmark$$

**（2）直接列等效电阻。** 接上负载后 P–N 之间：

$$R_{PN}=(30\parallel 60\parallel 80\parallel 80)\parallel 20$$
$$=13.33\parallel 20=8\ \Omega$$

电源支路总电阻 $40+8=48\ \Omega$，电源电流

$$I=\frac{120}{48}=2.5\ \text{A},\qquad V_{PN}=2.5\times 8=20\ \text{V},\qquad i=\frac{20}{20}=1\ \text{A}\quad\checkmark$$

**（3）支路电流与功率核对。** 各并联支路电流（$V_{PN}=20\ \text{V}$）：

| 支路 | 电流 |
| --- | :--: |
| $30\ \Omega$ | $0.667\ \text{A}$ |
| $60\ \Omega$ | $0.333\ \text{A}$ |
| $80\ \Omega$（斜） | $0.25\ \text{A}$ |
| $80\ \Omega$（竖） | $0.25\ \text{A}$ |
| $20\ \Omega$ | $1\ \text{A}$ |
| **合计** | $2.5\ \text{A}$，正好等于电源支路电流 ✓ |

功率：电源提供 $120\times 2.5=300\ \text{W}$；电阻耗散 $\sum I^2R$：

$$0.667^2\!\cdot 30+0.333^2\!\cdot 60+0.25^2\!\cdot 80+0.25^2\!\cdot 80+1^2\!\cdot 20+2.5^2\!\cdot 40$$

$$=13.33+6.67+5+5+20+250=300\ \text{W}\quad\checkmark$$

## 六、易错点

1. **把电路当成电桥。** 电桥的样子来自两条斜臂加中间两个"角"，但顶部、底部两条导线把 $30\ \Omega$、$60\ \Omega$、两只 $80\ \Omega$ 全都并到了同一对节点上。十字交叉处没有节点圆点，两斜臂不连接；若错把斜臂端点接到别的节点上，整题就成了另一道题，答案不会是这个干净的数。
2. **求 $R_0$ 时漏掉 $40\ \Omega$。** 电压源置零后，$40\ \Omega$ 是跨在 P–N 上的，必须并在分母里。
3. **求 $I_{SC}$ 时用"总电阻"算。** 短路态下并联电阻被短接，$I_{SC}=120/40$；用 $48\ \Omega$ 或 $120/(40+8)$ 得到的 2.5 A 不是短路电流。
4. **方向搞反。** $I_{SC}$ 取的参考方向应与 $i$ 一致（P→N，向下）；若设成向上，则 $I_{SC}=-3\ \text{A}$，分流后 $i=-1\ \text{A}$。按图中箭头，答案取正。
5. **分流公式记反。** 是 $i=I_{SC}\dfrac{R_0}{R_0+R_L}$（电流源被两电阻分），不是 $I_{SC}\dfrac{R_L}{R_0+R_L}$。$R_0$ 上分到的是 $3\times\frac{20}{30}=2\ \text{A}$，$20\ \Omega$ 上分到 1 A，合计 3 A，正好回到电流源。

## 七、诺顿定理的解题套路

| 步骤 | 动作 | 本题对应 |
| --- | --- | --- |
| ① 定端口 | 把待求支路（负载）从网络中去掉，标出端口 | 去掉 $20\ \Omega$，端口 P–N |
| ② 求 $I_{SC}$ | 端口短路，求短路电流（方向与待求量取同向） | $120/40=3\ \text{A}$ |
| ③ 求 $R_0$ | 电压源短路、电流源开路，从端口看等效电阻 | $40\parallel 30\parallel 60\parallel 80\parallel 80=10\ \Omega$ |
| ④ 画等效 | $I_{SC}$ 电流源 $\parallel$ $R_0$ | $3\ \text{A}\parallel 10\ \Omega$ |
| ⑤ 接回负载 | 分流公式或欧姆定律 | $3\times\frac{10}{10+20}=1\ \text{A}$ |

> 记法：**断负载 → 短路求流 → 置零求阻 → 电流源并电阻 → 接回负载分流**。这题的全部难度在第二步之前——先把"电桥画法、并联实质"看穿。
