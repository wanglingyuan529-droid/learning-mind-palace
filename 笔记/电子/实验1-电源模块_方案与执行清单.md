## 二、方案总览

### 2.1 技术路线（为什么这样选，答辩要能讲）

```
12V 输入 ──► 降压 DC-DC(MP2315) ──► 5V ──┬──► LDO(RT9080) ──► +3.3V
                                          ├──► 电荷泵(SGM3209) ──► −5V
5V 输入 ───────────────────────────────┘
                              （跳线二选一）
```

- **不用 7805/7905 线性方案**：12V→5V 线性效率只有 41%，发热大；7905 还需要负输入，成本高体积大。
- **不用单芯片多路电源**：贵、封装难焊、买料难。
- **buck + LDO + 电荷泵**：效率、成本、体积、手工焊接难度最平衡，全部是小封装贴片。
- 5V 输入时绕开 DC-DC 直通，避免"5V 进 5V 出"降压芯片顶不住的问题。

### 2.2 系统框图

```
 J1 12V ──F1──D1──┬── C_in ── U1 MP2315 buck ──L1── C_out ──► 5V_BUCK ─┐
                  │                                                      │
 J2  5V ──F2──Q1──┴── C_in2 ──► 5V_IN ─────────────────────────────────┐ │
                                                                       │ │
                              JP1 3P 跳线：1-2 = 12V模式，2-3 = 5V模式 │ │
                                                                       ▼ ▼
                                                             VCC5（主 5V 轨）
                                                                  │
                          ┌───────────────────────────────────────┼──────────────────┐
                          ▼                                       ▼                  ▼
                  U2 RT9080 LDO ──► +3.3V          U3 SGM3209 电荷泵 ──► −5V    指示灯/测试点
```

### 2.3 板级布局分区（画 PCB 前先定）

## 三、电路设计（参数可直接抄）

> 所有 IC 的连接以数据手册"典型应用电路"为准，本文档只给外围参数和容易错的点。**画之前把 datasheet 打开对着看引脚号。**

### 3.1 输入级（12V / 5V 双入口 + 保护）

**12V 通道（J1）**

```
J1-1 ──F1(0.5A)──D1(SS34)──┬── TVS1(SMBJ15A，可选) ──┐
                            ├── C1 10µF/25V ×2 ───────┤
                            ├── C2 0.1µF/50V ─────────┤
                            └── 到 U1 的 VIN ──────────┘   GND
J1-2 ── GND
```

- F1：**0805 贴片保险丝 0.5A/32V**（注意：0805 自恢复 PTC 多数只有 6V 耐压，12V 不能用；要么买 "0805 一次性保险丝 32V"，要么用 1206 PTC 0.5A/16V）。
- D1：SS34（SMA，3A/40V），防反接，压降约 0.4V，对后级无影响。
- TVS1：SMBJ15A，可选，抗浪涌用；不加也不影响功能。
- C1：0805 10µF/25V 两颗并联（陶瓷电容有直流偏压降容，12V 下实际容量会掉一半，所以并联两颗）。

**5V 通道（J2）**

```
J2-1 ──F2(0.5A)──Q1(AO3401 P-MOS 防反接)──┬── C3 10µF/16V ──┐
                                            └── C4 0.1µF ─────┴── 5V_IN（到 JP1 的 3 脚）
J2-2 ── GND
```

- Q1 接法（理想二极管/防反接）：**D 接 J2 侧，S 接 5V_IN 侧，G 经 10k 电阻到 GND**，G-S 之间并一颗 BZT52C5V1（SOD-123）钳位，防止误接高压把 Vgs 打穿。正常 5V 输入时压降只有约 30mV，比肖特基好得多（用肖特基 5V 轨就掉到 4.65V，−5V 会不达标）。
- 丝印必须写：**"J2 只接 5V！"**

**输入选择 JP1（1×3 贴片排针，2.54mm，带跳线帽）**

| 脚 | 连接 |
|---|---|
| 1 | 5V_BUCK（U1 输出） |
| 2 | VCC5（主 5V 轨，通往 LDO/电荷泵/LED/测试点） |
| 3 | 5V_IN（J2 支路） |

- 跳线帽插 **1-2 = 12V 输入模式**（buck 供电）
- 跳线帽插 **2-3 = 5V 输入模式**（5V 直通）
- 两种模式互斥，不会反灌，安全。

### 3.2 +5V 主路：MP2315 降压（12V→5V）

芯片：**MP2315GJ-Z，SOT-23-8，4.5–24V 输入，3A 同步降压**（立创常备）。
备选：MP1584EN（SOIC-8，4.5–28V/3A，参数不同需查手册，FB 也是 0.8V）。

**外围参数（12V 输入 / 5V 输出）**

| 元件 | 参数 | 说明 |
|---|---|---|
| R1（VOUT→FB） | **100kΩ 0805 1%** | 上分压 |
| R2（FB→GND） | **19.1kΩ 0805 1%** | 下分压，Vout = 0.8×(1+100/19.1) = **4.99V** |
| L1 | **6.8µH / 3A 屏蔽电感**，6×6 贴片（如 SRN6045-6R8M） | 饱和电流 ≥3A |
| C_IN | 10µF/25V ×2（0805） + 0.1µF/50V | 紧贴 VIN 与 GND |
| C_OUT | 22µF/16V ×2（0805） + 0.1µF | 紧贴电感输出端 |
| C_BST | 0.1µF/50V（0805） | 接在 BST 与 SW 之间，**不能省** |
| R_EN上 | 100kΩ 0805 | VIN → EN 分压上电阻 |
| R_EN下 | 20kΩ 0805 | EN → GND 分压下电阻；12V 输入时 EN≈2V 使能。**EN 不能悬空，也不能直接接 12V**（EN 脚耐压一般只有 6V） |

**设计计算（写进报告）：**

- 反馈：`Vout = VREF × (1 + R1/R2)`，MP2315 的 `VREF = 0.8V`；取 R1=100k、R2=19.1k → **Vout = 4.99V**。
- 电感：`L = Vout(Vin−Vout)/(Vin × fsw × ΔIL)`，取 fsw=500kHz、ΔIL=0.6A（2A 的 30%）→ **9.7µH**；实取 **6.8µH**（ΔIL 略大但常规取值，纹波仍很小）。若要更小纹波改用 10µH/3A。
- 输出纹波估算：`ΔV ≈ ΔIL/(8·fsw·Cout) ≈ 0.6/(8×500k×44µ) ≈ 3.4mV`，实测应 <30mV。

**容易错的点：**
1. **EN 不能悬空，也不能直接接 12V**（EN 脚耐压一般只有 6V）：用 100k/20k 分压接 VIN，EN≈2V 使能；悬空则芯片不启动。
2. **BST 电容不能漏画**，漏了芯片不工作或烧高侧管。
3. **输入电容必须紧贴 VIN/GND 引脚**（高 di/dt 环路），这是纹波和稳定性的关键。
4. **FB 分压从输出电容之后取**，FB 走线远离 SW 节点，走 0.2mm。
5. 电感下面**铺铜挖空**，不要走线。
6. 满载（1.5A）时 SOT-23-8 会温升，芯片底部散热焊盘要多打 4 个 0.4/0.8 过孔到地平面。

### 3.3 +3.3V：LDO（5V→3.3V）

芯片：**RT9080-33GJ5，SOT-23-5，600mA，固定 3.3V，陶瓷电容稳定**（立创常备）。
备选：SGM2019-3.3（SOT-23-5，300mA）、AMS1117-3.3（SOT-223，1A，但**对陶瓷电容不稳定**，见下）。

| 元件 | 参数 | 说明 |
|---|---|---|
| C_IN | 10µF/16V + 0.1µF（0805） | 靠 VIN 脚 |
| C_OUT | 22µF/10V + 0.1µF（0805） | 靠 VOUT 脚 |

- 功耗：从 5V 降到 3.3V，压差 1.7V；300mA 时 `P = 1.7×0.3 = 0.51W`。SOT-23-5 需要把 OUT/GND 焊盘周围**铺铜 ≥5×5mm**（双面更好）。
- **如果 3.3V 负载 > 350mA**：改第二片 MP2315 从 5V 降到 3.3V（效率 90%，不发热），不要硬用 LDO。
- **如果用 AMS1117 替代**：AMS1117 官方要求输出电容 ESR 0.1–1Ω（钽电容），直接上陶瓷容易振荡。要用的话输出并 22µF 陶瓷 + 串 0.1Ω/0805 电阻，或换成 47µF；建议优先 RT9080。
- RT9080 若带 EN 脚（SOT-23-5 常见），**EN 接 IN 使能**，不要悬空。

> **封装提醒**：MP2315GJ 的封装是 **TSOT-23-8**（不是普通 SOT-23-8 的大号），立创商城商品页会写"TSOT-23-8"，直接选官方封装库，不要自己按 SOT-23 画。所有 IC 画之前先核对封装名和引脚顺序。

### 3.4 −5V：反相电荷泵（5V→−5V）

芯片：**SGM3209YN5G/TR，SOT-23-5，输入 2.7–5.5V，输出 −Vin，100mA**（圣邦微，立创常备，¥1 左右）。
备选（电流更大）：LM27761（WSON-8，−5V/250mA，稳压输出）、MC34063A 反相（SOP-8，500mA，需要电感和二极管，外围麻烦）。

| 元件 | 参数 | 说明 |
|---|---|---|
| C_IN | 4.7µF/16V + 0.1µF（0805） | 靠 VIN |
| C_FLY | **1µF/16V（0805，X7R）** | 接芯片两个 CFLY 脚，**必须紧贴芯片（<5mm）**，这是电荷泵电流回路 |
| C_OUT | 10µF/16V + 0.1µF（0805） | 输出滤波；若纹波大再加一级 RC/磁珠 π 滤波 |

- 输出：`−5.0V`（跟随 5V 轨），100mA 以内。
- **注意**：飞电容容量不能随便加大（大了启动慢、效率降），按手册 1µF。
- 如果时间/买料实在紧张，**ICL7660（SOP-8，20mA）**也能出 −5V，但只够给运放用，电流小。

### 3.5 指示灯与测试点

**LED（0805，正向压降按 2.0V 算，电流 2–3mA）**

| LED | 颜色 | 接法 | 限流电阻 |
|---|---|---|---|
| +5V | 红 | VCC5 → 电阻 → LED → GND | 1kΩ 0805 |
| +3.3V | 绿 | 3.3V → 电阻 → LED → GND | 680Ω 0805 |
| −5V | 黄 | **GND → 电阻 → LED → −5V**（阳极接 GND，阴极经电阻到 −5V） | 1kΩ 0805 |

**测试点（1.0mm 圆形焊盘或 1.2mm 环）**

TP1 = 12V_IN、TP2 = 5V_BUCK、TP3 = VCC5、TP4 = +3.3V、TP5 = −5V、TP6/TP7 = GND（至少两个）。
丝印每个测试点旁写网络名，答辩时方便测。

### 3.6 输出端子

推荐 **1×8 贴片排针（2.54mm）**，顺序：`5V / 5V / GND / GND / −5V / GND / 3V3 / GND`（5V 用两针并联增加载流）。
若学校接受直插，可用 KF128-2P 螺钉端子，接线更牢；但纯"全贴片"要求下用贴片排针或贴片 XH2.54 座。

## 五、原理图绘制规范

1. **按模块分区画**：输入保护 → 5V buck → LDO → 电荷泵 → 指示/测试点。每块之间用网络标号（不要满图拉长线）。
2. **网络命名**：`12V_IN`、`5V_BUCK`、`5V_IN`、`VCC5`、`V3V3`、`VN5`、`GND`。
3. 每个 IC 的电源脚旁都画去耦电容，并且**在原理图上也画出来**（不要只在 PCB 加）。
4. 电源输入输出都加"网络标识"或注释文字，方便评审。
5. 画完跑 **ERC（电气规则检查）**，把"未连接引脚"逐一看清楚再消除；原理图 DRC/ERC 也尽量 0 错误（题目只要求 PCB DRC 0，但原理图干净不吃亏）。
6. 导出原理图 PDF（A3 或 A4），报告里要放。

## 六、PCB 设计规范（评分点主要集中在这里）

### 6.1 板框与定位孔

- **板框：45mm × 45mm 矩形**（<50×50，留余量）。
- **4 个定位孔：Φ2.7mm 非金属化（NPTH）**，坐标（板左下角为原点）：

| 孔 | X | Y |
|---|---|---|
| H1 | 3.5 | 3.5 |
| H2 | 41.5 | 3.5 |
| H3 | 3.5 | 41.5 |
| H4 | 41.5 | 41.5 |

- 孔边到板边距离 = 3.5 − 2.7/2 = 2.15mm（安全），孔周围 **1.5mm 内禁布铜/走线/丝印**。
- 立创 EDA 里放"非金属化通孔焊盘"：孔径 2.7，外径 2.7（无环），勾选非金属化。

### 6.2 层叠与工艺

- **2 层板**，板厚 1.6mm，铜厚 1oz，FR-4，绿色阻焊，白色丝印。
- 底层尽量做**完整 GND 平面**，只有必要走线时才让开；顶层 GND 铺铜 + 过孔缝合。

### 6.3 线宽 / 过孔规则表（直接照填）

| 对象 | 规则 |
|---|---|
| 电源网络（12V_IN、5V_BUCK、5V_IN、VCC5、V3V3、VN5、GND） | **线宽 0.5mm** |
| 控制信号（FB 反馈、EN、跳线控制） | **线宽 0.2mm** |
| 最小线宽（DRC 规则） | 0.2mm |
| 最小间距（DRC 规则） | 0.2mm（实际用 0.25mm 更稳） |
| 过孔 | **钻孔 0.4mm / 焊盘 0.8mm**（满足"内径 >0.3mm"），全板统一，不允许 0.3 及以下 |
| 过孔环宽 | ≥0.15mm |
| 铜到板边 | ≥0.3mm |
| 丝印到焊盘 | ≥0.15mm |

> **载流技巧（关键）**：0.5mm 线在 1oz 外层大约只能过 1.2A。方案里所有电源线**按要求画 0.5mm**，同时在同网络上下层**铺铜**并用多个过孔连起来——既满足"电源线 0.5mm"的评分要求，又有足够的载流和更低的压降。答辩时主动讲这一点会加分。

### 6.4 布局顺序（画之前先摆位置）

1. 先放 4 个定位孔和板框。
2. 左上：J1 → F1 → D1 → TVS1 → 输入电容 → U1 → L1 → 输出电容。
3. 左下：J2 → F2 → Q1 → 输入电容。
4. 中间：JP1 和 VCC5 主干，5 个测试点排一行。
5. 右上：U2 及其电容，3.3V 输出端子。
6. 右下：U3 及飞电容、输出电容，−5V 输出端子。
7. 最后放 LED 和限流电阻（放板边，方便看）。

### 6.5 布线要点（按优先级）

1. **buck 高 di/dt 环路最小**：`VIN 电容正极 → VIN 脚 → SW 脚 → 电感 → 输出电容 → GND 电容负极`，这个环路面积越小越好；输入电容紧贴 VIN/GND 脚（<3mm）。
2. SW 节点走 0.5mm 短粗线，**不要大面积铺铜**（铺铜会当天线增加 EMI），少量铺铜即可。
3. **FB 反馈线从输出电容之后取**，0.2mm，远离 SW 和电感，不跨过 SW 焊盘下方。
4. **底层 GND 完整**，功率地和信号地在 buck 输出电容处单点汇合；不要切开地平面（切地比"单点接地"更容易出问题，本方案用完整地平面）。
5. 电感正下方**禁止走线、禁止铺铜**（挖空）。
6. LDO 的 OUT/GND 焊盘周围铺铜散热（≥5×5mm，双面）。
7. 电荷泵的飞电容走线 <5mm，回路短；−5V 输出走线 0.5mm。
8. 电源换层处至少打 **2 个过孔**；芯片散热焊盘打 4 个过孔。
9. 走线避免锐角/直角倒 45°；差分这里没有，不用管。
10. 板边 0.5mm 内不走线不铺铜。

### 6.6 丝印内容（必须写全）

- 板名：`Power Module Lab-1`
- 学号 + 姓名
- `J1 = 12V IN`、`J2 = 5V IN（只接5V！）`
- `JP1: 1-2=12V输入 / 2-3=5V输入`
- 输出端子每个脚标：`+5V`、`GND`、`-5V`、`+3.3V`
- 3 个 LED 旁标 `5V`、`3.3V`、`-5V`
- 测试点标网络名
- 版本号 + 日期（如 `V1.0 2026-11`）

## 七、DRC 0 错误操作规程

### 7.1 先设规则，再布线

| 规则项 | 设定值 |
|---|---|
| 最小线宽 | 0.2mm |
| 最小间距 | 0.2mm |
| 最小过孔钻孔 | 0.3mm（实际全用 0.4） |
| 过孔焊盘 | 0.8mm |
| 铜到板边 | 0.3mm |
| 丝印到焊盘 | 0.15mm |
| 孔到孔 | 0.3mm |

### 7.2 检查顺序（照做，5 分钟出 0 错误）

1. **飞线检查**：所有网络都布通，"未布线"数量 = 0。
2. **重新铺铜**（铺铜后 DRC 才准）。
3. 运行 **DRC**。
4. 逐条修：
   - `线宽小于规则` → 改宽（电源必须 0.5mm）。
   - `丝印压焊盘` → 移动丝印文字。
   - `孤铜/铜皮碎片` → 删除或重新铺铜。
   - `板边距离不足` → 移线或缩铜。
   - `孔环太小` → 用标准 0.4/0.8 过孔。
   - `网络未连接` → 补线。
5. 再跑一次 DRC，**直到错误 = 0**（警告也尽量清零）。
6. **导出 DRC 报告 PDF + 截图**，报告里放。
7. 用"网表对比/元件检查"确认 PCB 元件与原理图一致（防止漏画/多画）。
8. 导出 Gerber → 用立创 Gerber 查看器逐层检查：板框、钻孔、阻焊、丝印、铜层。

> 注意：DRC 的坑多数是"先布完线再改规则"和"铺铜后没重铺就查"。按上面顺序做基本一次过。

## 九、焊接与分步上电调试（防炸板流程）

**焊接顺序**：先低后高，先阻容后 IC。

1. 先焊保险丝、TVS、二极管、PMOS、所有 0805 阻容（IC 先不焊）。
2. **上电前测短路**：万用表电阻档测 J1 的 12V 与 GND 之间、VCC5 与 GND 之间，不能是 0Ω（电容充电会有跳变，正常）。
3. 只接 12V 到 J1（跳线拔掉）：测 C1 电压 ≈ 11.6V（经过 D1 压降）。
4. 焊 U1 + L1 + 反馈电阻 → 12V 输入、输出接 100Ω/2W 假负载 → 测 5V_BUCK 应为 4.95–5.05V；示波器看 SW 波形（500kHz 方波，无剧烈振铃），测输出纹波应 <50mV。
5. 焊 U2 → 测 +3.3V（3.23–3.37V）。
6. 焊 U3 → 万用表红笔接 GND、黑笔接 −5V 测出 +5V，或红笔接 −5V、黑笔接 GND 读 −5V；输出应 −4.9～−5.1V。
7. 插上跳线到 1-2，测 LED 全亮（3 个）。
8. 拔 12V，改接 5V 到 J2，跳线改 2-3，重复测 VCC5、3.3V、−5V。
9. 负载测试（见第十节），记录数据。
10. 满载跑 10 分钟，手摸/测温枪测 IC 和电感温度（应 <60℃）。

**调试记录**：每一步的实测值都要记，直接填进报告表格，别等最后补。

## 十四、常见坑（照着躲，能省一天）

1. **0805 PTC 只有 6V 耐压**，12V 输入用它会击穿——买 0805 一次性保险丝 32V 或 1206 PTC。
2. **MP2315 的 EN 悬空** → 不启动，必须经 100k 接 VIN。
3. **BST 电容漏画** → 芯片不工作或炸高侧。
4. **AMS1117 + 陶瓷电容** → 振荡；用 RT9080 或给 AMS1117 串 0.1Ω。
5. **5V 输入用肖特基防反接** → 5V 轨掉到 4.65V，−5V 不达标；5V 通道必须用 PMOS 防反接。
6. **−5V 测试接反**：万用表黑笔接 −5V、红笔接 GND 才是正读数；LED 的阳极要接 GND。
7. **DRC 前没重新铺铜** → 查出假错误；铺铜后重跑。
8. **定位孔画成金属化**且铺铜连孔 → 螺丝短路；用非金属化，孔周禁布。
9. **电源线只画 0.5mm 不铺铜** → 1A 以上压降大、发热；加同网络铺铜。
10. **电感下面铺铜/走线** → 涡流损耗、纹波变大；挖空。
11. **丝印压焊盘** → DRC 报错且贴片后看不清；提前移开。
12. **打样只买 1 套元件** → 焊坏一片就停工；多买 1.5 倍。
13. **忘记导出 DRC 报告截图** → 报告缺证据；设计完成时立刻截图存档。
14. **提交前没检查文件包** → 少 Gerber、少源文件；按第十二节清单核对。

## 附录 A：备选方案

### A1. 要求「12V 和 5V 同时接入、自动选择」

- 12V 路 buck 输出设 **5.4V**，经 SS34（0.4V）汇入 5V 轨；
- 5V 路经 **理想二极管（MAX40200，SOT-23，压降 42mV）** 汇入 5V 轨；
- 两条支路互不反灌，任一输入都能工作。
- 缺点：5V 路 5.4V 设计要改 FB 电阻（R2=18.7k），且多一片贵料；课程实验一般不需要，跳线方案就够。

### A2. −5V 需要 >100mA

- 用 **LM27761**（−5V/250mA，WSON-8）或 **MC34063A 反相**（SOP-8，可到 500mA，需 100µH 电感 + SS34）。
- MC34063 反相外围：定时电容 1nF、电感 100µH、二极管 1N5819/SS34、反馈电阻按 `Vout = −1.25×(1+R2/R1)` 计算。

### A3. 3.3V 需要 >350mA

- 加第二片 **MP2315**（5V→3.3V），FB 电阻 R1=100k、R2=31.6k（0.8×(1+100/31.6)=3.33V）。

### A4. 完全买不到 MP2315

- **MP1584EN**（SOIC-8，4.5–28V/3A）：FB 0.8V 同公式；电感 6.8µH；RT 电阻按手册设 1.5MHz；EN 用 100k/20k 分压接 VIN（不要直接接 VIN）。
