# 🏛️ learning-mind-palace

**学习记忆宫殿** —— 每天学了什么、卡在哪、多久后要回来复习，都记在这里。
目标不是"存下很多笔记"，而是**三个月后能一眼看出自己走到哪、哪些东西真的会了**。

---

## 🚀 每天怎么用（3 步，5 分钟）

1. **新建日记**：在 `日记/2026/` 下建 `YYYY-MM-DD.md`，从 [`每日日记模板`](模板/每日日记模板.md) 复制内容。
   时间紧就抄 [`轻量版`](模板/每日日记模板-轻量版.md)，四行也能交差。
2. **只填三样东西**：今天一句话、学了什么（每条一个点）、卡在哪。
   剩下标 `【选填】` 的段落可以空着。
3. **更新进度**：打开 [`索引/学习进度.md`](索引/学习进度.md)，把碰到的主题状态改成 `🔄`，填上今天的日期。

> 💡 **推荐用 [Obsidian](https://obsidian.md) 打开这个文件夹**（直接把整个目录当 vault）。
> 笔记之间的 `[[双链]]` 只有 Obsidian 能跳转；在 GitHub 网页上只能看到纯文本。
> 本文档里的链接用的是相对路径，网页和 Obsidian 都能点。

## 📂 目录结构

```
learning-mind-palace/
├── 日记/                     ← 每日流水（唯一的"每天都要写"的地方）
│   └── 2026/2026-10-29.md
├── 笔记/                     ← 成体系的知识笔记（写一次，服务很多天）
│   ├── Java/                 ← 6 篇教程 + 阶段测试卷
│   └── 英语/单词本.md        ← 所有生词的累计总表
├── 模板/                     ← 三种模板，复制就行
├── 索引/
│   └── 学习进度.md           ← ★ 全局进度表 + 待复习队列
└── .obsidian/                ← Obsidian 配置（风格、插件开关）
```

**日记 vs 笔记 的分工：**

| | 日记 `日记/` | 笔记 `笔记/` |
| --- | --- | --- |
| 记什么 | 今天干了啥、哪里卡住 | 一个知识点完整长什么样 |
| 长度 | 5 行也行 | 几百行，越完整越好 |
| 频率 | 每天 | 一个主题学完写一次 |
| 关系 | 日记里链接到笔记 | 从日记里长出来 |

## 📏 命名规范

| 类型 | 命名 | 例子 | 为什么 |
| --- | --- | --- | --- |
| 日记 | `YYYY-MM-DD.md` | `2026-10-29.md` | 文件名排序 = 时间排序；不出现中文标点，命令行/链接都不会出错 |
| 教程笔记 | `主题名教程.md` | `集合进阶教程.md` | 一眼知道是"教程"而不是"草稿" |
| 习题/试卷 | `科目_范围_类型.md` | `Java_变量到OOP_测试卷.md` | |
| 索引 | 固定名 | `学习进度.md`、`单词本.md` | 靠双链引用，名字不能变 |

> ⚠️ 原来用「2026年10月29日.md」这种格式，问题是：按文件名排序时 `10月` 会排在 `2月` 后面，
> 而且中文标点在 URL 里要转义。统一改成 ISO 日期。

## 🏷️ 标签体系

写在文件开头的 frontmatter 里（Obsidian 自动识别，可以按标签筛）：

| 层级 | 标签 | 用途 |
| --- | --- | --- |
| 类型 | `#日记` `#笔记` `#索引` `#模板` `#错题` | 区分文件性质 |
| 科目 | `#Java` `#英语` | 按科目筛 |
| 细分 | `#Java/集合进阶` `#Java/泛型` | 专题级，**限两层**，别加三层 |
| 状态 | `#待复习` `#已掌握` | 复习用 |

## 🔁 复习机制（这是整套东西的核心）

学完当天不算会。**隔 1 天、3 天、7 天各回来看一次**，只看 [`学习进度.md`](索引/学习进度.md) 底部的「待复习队列」。

- 自测题答不出来 → 给那篇日记加 `#待复习` 标签
- 「待复习队列」每月清一次，清完就是真的会了
- `🔥` 标记的生词超过 20 个时，**先别加新词**，清库存

```bash
# 提交很慢或超时 → 走本机代理（先探测端口，别写死）

       | grep -oE '127\.0\.0\.1:[0-9]+' | head -1 | cut -d: -f2)
git -c http.proxy="http://127.0.0.1:$PORT" -c https.proxy="http://127.0.0.1:$PORT" push
```
